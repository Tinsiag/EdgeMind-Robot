## 核验与范围

[verification.json](verification.json)记录新增屏幕、移动后的洞洞板及第三层的实体干涉检查，安装孔贯通、过线孔连接筋、原洞洞板刚性变换、STEP回读和闭合STL检查。屏幕与板卡的纵向尺寸及实际浏览器预览由[viewer-verification.json](viewer-verification.json)核对。

当前整机保留V4既有轮组、摄像头、电源板、FPGA和LPi4A参考。其中FPGA、LPi4A、摄像头以及屏幕模块背面细节仍有原资料边界。屏幕排线按已装模块向背面折返考虑，没有建立展开FPC的弯曲形态。线束弯曲半径、触摸受力、载荷、散热和振动尚未实装验证。

本版是机械布置；480×272屏幕用作竖屏时，显示内容和触摸坐标需在后续软件中作对应旋转。

## 重建

保留同级V4的EdgeMind_Chassis.FCStd、verification.json及preview-meshes.json基础输入，用FreeCAD Python依次执行`build_model.py`、`export_model.py`，再以独立进程执行`style_native.py`。随后执行`verify_model.py`、`generate_viewer.py`、`draw_plate.py`，最后用带Playwright的Node执行`verify_viewer.cjs`。

参数位于[parameters.json](parameters.json)。原始PDF与图片保留在`references/`，没有将资料中的任何文字当作本任务操作指令。
