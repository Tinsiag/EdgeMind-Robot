## 资料边界

MPU 附图明确标了板框、φ3 安装孔和 2.54 排针间距，没有标安装孔中心距或边距。这里根据图中比例暂取 15.24 孔距、2.54 孔边距，第三层开短槽留余量。PCB 厚度、芯片和排针高度也属于安装参考。**加工前应测量 MPU 实物孔距并复核短槽位置。**

雷达和洞洞板直接使用本次用户提供的 STEP；洞洞板源文件只有裸板，没有焊接后的元件和线材。雷达隔柱及螺钉长度须核对实物沉孔和螺纹。模型中的紧固件用简化圆柱表示，不建立螺纹牙型。

已检查新增结构与现有装配的实体干涉、第三层板孔贯通、STEP 回读、STL 闭合和源模型等比例保持。雷达上部光学区高度以上，模型中没有其他零件遮挡；实际走线和洞洞板后续焊接器件应另行确认。原 V3 的 FPGA、LPi4A 和摄像头仍为安装包络参考，电源板仍为旧版 100×50 模型。未进行线束、载荷、振动或散热计算。

## 重建

重建需保留同级完整 V3 目录；压缩包中的预览和导出模型可独立查看。使用能够导入 `FreeCAD`、`Part`、`MeshPart` 的 FreeCAD Python 依次执行：

1. `build_model.py`
2. `export_model.py`
3. `verify_model.py`；仅改动第三层时可用 `verify_model.py --changed-layer`，保留新增层完整实体与体积检查，整机检查导出拓扑和每个实体的包围盒
4. `generate_viewer.py` 和 `draw_plate.py`
5. 用带 Playwright 的 Node 执行 `verify_viewer.cjs`

参数在 [parameters.json](parameters.json)。源数据保存在 `references/`，源文件 SHA-256 和核验结果保存在 `verification.json`。FreeCAD 保存独立实体，不是全约束草图；改动参数后重新运行脚本。原 V3 文件不覆盖。
