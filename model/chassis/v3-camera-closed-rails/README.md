两处过线孔中心来自原模型的连接器包络，单位mm：左 `X=-47.225, Y=28.6951`，右 `X=47.225, Y=91.3000`。电机本体和连接器保持原模型位置。

## 摄像头资料边界

用户给出的 [机械图](references/OV5640-mechanical-drawing.png) 明确标注30×30mm板框、底部24mm孔距、镜筒直径14mm、2.54mm排针间距和一段24.60mm轴向尺寸。

图中没有明确标注PCB厚度、安装孔直径和底孔距板边的尺寸；模型分别以1.6mm、3.2mm、约3mm作为安装参考，并用可调槽留余量。侧视图24.60mm的尺寸线没有覆盖最前端镜筒，镜头整体前伸暂按约33mm的保守参考包络表达。摄像头模型用于安装与避让，并非厂家完整精确STEP；支架的实际孔径、紧固件和镜头前伸应以实物确认。

电源板仍沿用V2的100×50mm原STEP，FPGA与LPi4A仍为原尺寸包络参考。尚未把约96×97mm的AI电源PCB替换进机械装配。

## 核验与重建

`verification.json` 记录双层5mm、摄像头安装尺寸、两处孔的实际位置、上层分组移动、连续围栏、原轮组几何一致性、STEP回读、STL闭合性和关键体积干涉。`viewer-verification.json` 记录真实浏览器显示、摄像头特写及上层一起展开的结果。

在完整项目目录中使用 FreeCAD Python 依次执行：

1. `build_model.py`，读取V2已验证的原生装配，直接修改实体。
2. `export_model.py`，导出STEP、STL、原生展开装配和真实几何网格。
3. `verify_model.py`，回读并检查模型。
4. `generate_viewer.py`，生成离线HTML和GLB。
5. 用Node运行 `verify_viewer.cjs` 生成浏览器验证与截图。本机依赖路径可按安装位置调整。

V2源文件保留不覆盖。本轮核验为几何与装配检查，不代替载荷、加工公差与线束实装验证。
