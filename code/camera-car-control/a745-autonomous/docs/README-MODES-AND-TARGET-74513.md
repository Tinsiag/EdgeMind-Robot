## 本地操作

| 按键 | 行为 |
|---|---|
| S0 | 复位停车，恢复默认模式1；摄像头和网口也重新初始化 |
| S2 | IDLE待机时下一模式，1→2→3→1 |
| S3 | IDLE待机时上一模式，1→3→2→1 |
| S1 | 启动所选模式；校准、等待或运行中再次按下停车 |

数码管常亮显示模式1、2或3。上电松开即可用第一次新按键启动；上电按住不启动，需先释放。运行和DONE时选模式键忽略：先S1停止回IDLE，再选模式和重新启动。网页只能选目标，不能ARM。电脑不模拟本地按键。

启动依次经过传感器健康检查、连续车轮静止窗口、64次有效陀螺仪采样校准、约1秒READY等待。真实IMU、倾角22.5°、CPU、非法编码器跳变和雷达故障保护保留；编码器无脉冲1秒仍只提示。

## 三种模式

1. **绕障行驶**：前方雷达原点距离≤300mm立即禁止前进，开阔处120mm/s，其余可行区60mm/s。转向须同时满足原CAD转向包络和新转后200mm出口检查；左右扇区600mm最小值不再作为唯一通路门槛。都通优先左绕。典型过程为左90°、横移、右转恢复原航向、越过障碍、右90°、按横移轮计数返回、左转恢复原航向。每次转向前停车150ms，转后停稳150ms。横移至少约350mm、平行越过至少约800mm，并要求连续约200ms出口安全；段长最多约1.5m/25秒，绕行受阻最多等待10秒。它没有全局定位或障碍地图，回线精度需要实测。
2. **原地一圈**：完整扫描和全周车体旋转包络许可后，按IMU有符号角度增量累计约360°，跨±180°不丢圈。轮速80→40mm/s，约357°撤销转动并停稳，最终实际角度受惯性和地面影响。总超时30秒，明显反向或转角异常锁存ERR0080；前置空间不足等待至多30秒，转动中新障碍立即结束停车。完成保持DONE，不自动前进。
3. **视觉寻物**：网页 `http://192.168.40.101:8090/` 选COCO类别，Apply后在本地模式3按S1。4A发有限搜索、对准、接近或本地绕障请求，FPGA独立检查会话、新鲜度、雷达几何及全部联锁。单次运动最多0.5秒/200mm或约10°，必须经过STOP再开下一段；总任务最多120秒或任一轮累计绝对路程约3m，往返也累计。换目标先STOP并取消旧绕行。丢链路、画面冻结或旧观测立即撤销动作，需本地重新启动才能恢复过期会话。

三方确实受阻时，仅在前方≤300mm、后方严格>350mm、后退100mm扫掠几何安全且本堵塞阶段尚未尝试时，以60mm/s短退；任一轮约100mm或2秒即停，停稳150ms重新择路。侧边各约500mm本身不会触发倒车。弱反射且不足三个邻接点的细物仍可能被过滤，模型几何不能替代真实制动与安装验收。

## 单目标确认与测距

不做颜色识别。默认置信度0.65，至少三次不同源帧，框位置和尺度连续，意外多候选拒绝；重复帧不增加确认次数。连续误识别仍有可能，多帧确认不等于正确率保证。

当前默认相机内外参**未验证**，目标雷达可观测性**未验证**，自动接近和到达判定因此保持禁用。候选可以在未ARM时从网页观察。请使用直立、不透明、在雷达平面有足够宽度的实物，先测相机/雷达安装位置、视角和扫描高度，并在多个距离检查同一目标的图像与雷达点簇。YOLO能识别的小杯、手机或地面低物未必会被雷达看到。

关联要求新鲜雷达点簇至少3点、距离集中，并在目标框两侧存在足够深度断差，避免把连续墙面当目标；没有关联距离时停车，不能用框大小冒充实测距离。初始到达范围为**雷达距离450～600mm**，不是车头净空500mm；仍须实测制动余量。不要未经专项验证用移动人员演示接近。

## 视频与协议

原摄像头/DDR/TFT链路及HUD置顶保留：本机800×480/33MHz，EV10 UDP6104裁剪640×480；4A等比填充至640×384 NPU，目标5Hz；网页目标15fps；ED10 UDP6105最多8个绿色框回传，x坐标+80，过期清框。检测框叠最新本地画面，有推理时延，不是同源帧锁定。

ET10独立UDP6106、48字节，要求固定MAC/IP、IP/UDP校验、非分片、长度、动作字段、单调序号、本地session与源EV10帧龄。期限400ms，观测总龄<600ms，本机真实摄像头完整帧也须更新。EMT1 64字节经UDP6103报告模式、阶段、原因和旋转累计。地址与session不是加密鉴权，只用于当前隔离有线链路。

新增任务RX确实可以在本地ARM模式3影响电机。原“整个RX到电机不可达”的旧证明已经不适用；本版本核验解码后的ED10框/类别/分数数据隔离，以及ET10本地会话/故障/新鲜度约束。ED10更新/ready共享流控，诊断计数通过TX RAM在保守全位图上也可达新鲜度，因此不将控制/诊断路径宣称结构隔离。校验正确的ED10端口/魔数输入被任务解析器拒绝；模式1/2及未ARM模式3的网络隔离由连接的core回归检查。共享接收链路拥塞可能造成停车，不可宣称任意网络流量都没有时序影响。
