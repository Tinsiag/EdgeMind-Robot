# 基础避障网口协议

EMC1会话封装及双CRC沿用现有实现，只有STOP可建立新会话，旧请求号拒绝执行。UDP控制5000/5001，遥测6103。没有视频或地图通道。

| 命令 | 载荷 | 行为 |
| --- | --- | --- |
| 0x02 / 0x03 / 0x04 | 无 | ARM / DISARM / STOP |
| 0x05 | 无 | 外部控制租期续租；不启动运动 |
| 0x11 | 左右轮速各int32，小端 | 原始轮速调试，无应答；不能抢占避障 |
| 0x20 / 0x21 | 无 | 状态 / 静止且未ARM时清故障 |
| 0x30 / 0x44 | uint8键+uint32值 / uint32键 | 设置 / 读回 |
| 0x40 / 0x41 / 0x43 | 无 | 能力 / 传感器 / 静止校准 |
| 0x46 | uint16 | LD06占空比0或200～600‰ |
| 0x56 / 0x57 | 无 | 取消并解除ARM / 基础状态 |
| 0x59 | uint8，1启动、0停止 | 显式启动或停止避障；重复启动拒绝 |

0x42、0x45、0x47及旧地图/航点命令被协议解析器拒绝。运动命令不自动重试。

0x57回复类型0xD0，共32字节，小端：

| 字节 | 内容 |
| --- | --- |
| 0 | 0成功；非0拒绝 |
| 1 / 2 | 避障状态 / 原因 |
| 3 | bit7 CAD配置有效，bit6 yaw有效，bit5 roll/pitch有效，bit2手动保护扫描有效，bit1避障扇区有效，bit0避障活动 |
| 4～5 / 6～7 | roll / pitch，有符号Q15；180°对应32768 |
| 8～11 | 保留0 |
| 12～13 | yaw，有符号Q15 |
| 14～15 / 16～17 / 18～19 | 前 / 左 / 右距离mm |
| 20 | bit0 CPU有效，bit1 CPU故障 |
| 21 | 保留0 |
| 22～25 / 26～29 | CPU进度 / 编译配置CRC32 |
| 30 / 31 | 基础接口标志1 / 版本1 |

0x59应答仅byte0表示结果，不把它当作0x57状态。启动仍要求已ARM、无故障、外部租期、CPU有效、配置有效且无手动轮速目标；不自动校准或ARM。

EMS1传运动/传感器状态，EML1传CRC核验后的LD06数据，EMF1传48字节基础状态。EMF1中byte20～23为roll/pitch，byte24 bit0为tilt_valid，byte28～29为yaw；yaw有效性来自EMS1。已删除的位姿/地图字段为保留值。上位机不可把过期快照或有效位为0的角度作为当前测量。
