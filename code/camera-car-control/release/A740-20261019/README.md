## 连接与上位机

1. 电脑和FPGA直接用网线连接，电脑静态IPv4设为 `192.168.0.3`，掩码 `255.255.255.0`。本版仅支持协商为1Gbps。
2. 从工程根目录运行 `launch.cmd`，选择UDP，FPGA地址 `192.168.0.2`、控制端口5000。本机控制端口5001，视频端口6102，视频来源为FPGA地址。
3. 保留摄像头P7接线，不换成原厂P4接口。首次验证先断开电机VM，仅检查PLL/初始化LED及静止画面，再进行架空电机测试。
