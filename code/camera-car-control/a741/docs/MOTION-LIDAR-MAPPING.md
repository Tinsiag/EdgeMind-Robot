# A741 LD06 二维建图

运动+LD06构建的上位机在“雷达扫描”和“2D地图”页分别显示实时扫描和累计地图。地图在电脑本地生成，不在FPGA上运行SLAM。

## 开始前

1. 使用与本次软件相匹配的 `A741-MOTION-LD06-H20-H14` 固件。当前构建 `timing_signed_off=false`，不是时序签核或运动验收版本；电机 VM 保持断开，直到完成独立硬件核查。
2. LD06 `CTL` 接 H20，雷达 `TX/DATA` 接 H14，供电按模块规格连接并共地。H14在开发板管脚表中复用 `USB_PA3`，确认USB外设没有同时驱动该网络。不要把不兼容的5 V UART直接接入FPGA。
3. 电脑通过RJ45直连，电脑 IPv4 为 `192.168.0.3/24`，FPGA 为 `192.168.0.2`。运行 `launch.cmd`、连接，在“雷达扫描”页启动雷达；确认扫描连续且没有“无效/过期”。
4. 机器人平放静止、MPU6050按Z轴水平安装，运行“静止校准”，确认IMU样本有效、故障为零。
5. 先手动低速、小范围移动观察方向和比例。错误时检查左右CPR、轮径、IMU方向、雷达角度方向及安装位置，不要靠拖动画布修改数据。

## 操作

- “新建地图”清空旧累计结果，等待一圈有效LD06扫描及时间匹配的FPGA里程/航向遥测后开始积分。
- “暂停”冻结地图。暂停期间移动后，不要把新数据接到旧地图；再次点击“新建地图”开始新图。
- “保存”生成同名 `.png`、`.pgm`、`.yaml` 和 `.json`。JSON包含轨迹、末次输入序号/时间、配置及SHA-256、栅格分辨率和匹配方法。
- “清空”清除内存地图。断流、坏包、丢整圈、遥测过期、IMU无效、时间差超过100 ms、运动跳变或匹配越界时会冻结积分并显示原因；恢复后新建地图。
- 鼠标滚轮或加减按钮缩放，按住左键拖动地图；2 m标尺随缩放更新，导出始终保存全尺寸地图。
- “停止雷达”也会发送整车STOP；运动任务取消、失焦或界面租约过期会撤销雷达PWM。普通DISARM不撤销已启用雷达PWM。这里“停止”只描述软件请求与H20波形，不是雷达断电或实际转子停转保证，须按当前模块CTL模式实测；需要确定停转时按模块说明切断其电源。恢复PWM需人工显式启动，建图故障恢复须新建地图。

## 地图含义与限制

CoreSLAM RMHC执行相邻扫描的局部匹配并累积占据栅格。当前600×600像素覆盖30×30 m，即0.05 m/像素；地图原点在中心附近。YAML分辨率与输出图像尺寸一致。

这是实验用二维局部地图，不提供全局回环闭合、重定位、目标点导航或动态避障。MPU6050只给相对Z轴航向，会随时间漂移；轮径、CPR、打滑和雷达安装偏移都会累积成比例/角度误差。扫描整圈时间戳与最近FPGA遥测关联，要求差值不超过100 ms，但不是硬件同步；当前也没有逐点运动去畸变。快速转动、轮胎打滑、遮挡或地面不平会导致匹配失败或地图变形。

LD06目前只用于采集、显示和建图，不参与电机自动避障。VL53L1X未接入，因此没有前向测距停车保护。首次验证用架空/手推和低速空旷场地，保持物理急停可触达。

## 构建与验证

已固定CoreSLAM/BreezySLAM LGPL-3.0-or-later源码和许可证。重建本地DLL需按 `scripts/setup_mapping.py` 安装 `ziglang==0.13.0`，然后运行该脚本；运行时Pillow依赖见父目录 `requirements.txt`。执行 `scripts/check.py` 可运行RTL与主机回归。仿真通过不代表雷达已接线、固件已烧录或实车地图验收。
