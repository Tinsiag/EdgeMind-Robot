## 有效资料与旧图撤销

有效资料为[商品规格图](images/mpu6050-product-spec.jpg)、[引脚说明图](images/mpu6050-product-pins.jpg)及下述CSV。商品页标注VCC输入DC 3～5 V，用户确认采用3.3 V供电；不能据错误旧图要求改接5 V。照片显示单排8针，具体接线按实物丝印识别，不能将图片左右方向直接当针号。上拉电阻、上拉电源轨、稳压器参数及AD0默认电平仍未知。商品页混用MPU6000/6050系列SPI/9轴说明：MPU6050本体是六轴I2C器件；本工程不启用SPI、磁力计或绝对航向。

用户提供的[ACG720管脚分配表](hardware/acg720-pin-assignment.csv)中，六个球号均标 LVCMOS33：L18=COMS_SDAT、M20=COMS_SCLK、A1=COMS_HREF、B2=COMS_VS、M17=COMS_XCLK、B1=COMS_PCLK。新用途严格遵循用户实接 SCL=L18/SDA=M20，不按原网络名交换。该表补充3.3V I/O标准依据，但未列出连接器针号、Bank编号及实测VCCIO，不能称实际Bank电压已测量。

旧图的CON1/CON2、J1/J2针序、VCC_5V/VCC_3.3网络、4.7 kΩ上拉和AD0下拉结论全部撤销。自动探测0x68/0x69不能证明AD0已经有确定电平。FPGA对M17保持高阻，待核实模块地址选择网络。

CSV第94～99行分别为M17/B1/A1/B2/L18/M20，I/O标准均为LVCMOS33。文件部分中文字段已经是问号，不能从中恢复连接器名称；英文信号名、球号及I/O标准可读。该CSV未提供连接器针号或Bank编号。

**板卡端仍待核实：** 用户提供的球号为 SCL=L18、SDA=M20、XDA=A1、XCL=B2、AD0=M17、INT=B1；它们不是排针针号。CSV确认原网络名和LVCMOS33标准，连接器实际针号、Bank VCCIO及模块SCL/SDA空闲电平仍待核实。不得从已撤销的旧图假定上拉为3.3 V。

## 代码核对

### 用户实测电压（2026-10-20）

用户报告对模块GND测得：VCC=3.3 V、SCL=3.3 V、SDA=3.3 V、AD0=3.2 V。SCL/SDA在测量时为空闲高电平，AD0为高，对应预期7位地址0x69；这不是已获得I2C ACK或WHO_AM_I的证明。读数稳定性、测量时是否保留FPGA信号连接未单独确认。上拉阻值/来源和实际Bank电压仍不能由这些读数确定，FPGA M17仍保持高阻。当前已交付位流的物理传感器端口仍禁用，资料更新不会使其具备读数能力。

## 用户接线与限制

| 模块信号 | FPGA 球号 | 当前设计 |
| --- | --- | --- |
| SCL | L18 | 主 I2C 开漏；按用户实接，不能沿用旧摄像头 SCL 网络名 |
| SDA | M20 | 主 I2C 开漏 |
| XDA | A1 | 辅助 I2C 数据，高阻，不作为主 SDA |
| XCL | B2 | 辅助 I2C 时钟，高阻，不作为主 SCL |
| AD0（用户写 ADO） | M17 | 地址选择；默认电平未知，FPGA保持高阻 |
| INT | B1 | 输入预留，当前驱动轮询 INT_STATUS，不依赖中断边沿 |

供电按用户确认的3.3 V记录。主通信只用SCL/SDA，XDA/XCL为辅助I2C，当前保持高阻；INT输入预留，驱动轮询INT_STATUS。AD0低时7位地址0x68、高时0x69，不能假定模块已有下拉。当前位流依然是传感器端口禁用版本，本次资料更新不会改变已烧录固件。

## 相对航向

当前为小车平放 Z 轴转动用途。64 个静止样本估计 Z 轴角速度零偏，加速度用于检查安装近似水平及重力幅度。校准后对校正角速度按 FPGA 采样间隔积分，输出与旧协议兼容的 16 位环绕航向。

这是**相对航向**，不是绝对方位，也不是完整三轴姿态解算。加速度不能校正绕重力轴的航向漂移；长期漂移、震动、温漂及打滑仍需实测。安装倾斜或任意轴安装暂不支持，不能用清零航向掩盖误差。

未校准时内部相对航向保持 0，上位机标记“未校准”。当前 FPGA OSD 的 YAW 字段仍显示该初始化零值，需结合 calibrated 遥测标志判断，尚待补齐 HDMI 的“未校准”独立文字提示。

超过 30 ms 的采样间隔跳变使航向无效；数据流超过 150 ms 失效。IMU 故障撤销运动输出并作废校准；恢复后须人工清故障、静止校准和重新启动，不会自动续跑。

配置模型改为 MPU6050，revision 初始 74102。只读配置 key12=6050，主机连接必须核对；原 JY901 诊断位流会被拒绝。

旧 JY901 构建保存在 release/A741-DIAGNOSTIC-20261020-094133，仅为变更前诊断快照。其位流不支持本次 MPU6050，不能因 User Code 同为 A741 而替换使用。
