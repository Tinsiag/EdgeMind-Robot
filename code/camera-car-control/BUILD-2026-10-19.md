## 时序结果

工具总体报告：Setup Violated Endpoints **3**，Hold Violated Endpoints **26**。最差RGMII输入hold slack **-1.526ns**；还包含异步FIFO指针、提交握手、复位同步器的跨时钟路径。3项setup统计对应报告中的接收复位recovery路径，常规setup路径表最差为 **+0.016ns**。

各时钟内部setup汇总TNS为0，Fmax分别为：原始50MHz域50.183MHz、摄像头100MHz预算100.158MHz、RGMII RX125MHz域145.779MHz、网络PLL50MHz域55.784MHz、TX125MHz域175.896MHz。裕量有限，不能据此宣称全设计时序闭合。

SDC对摄像头输入和RGMII双沿输入使用初始延迟预算；这些不是板级测量。PHY延迟绑定位、RGMII输出时序、异步路径的有界延迟/偏斜约束及实板链路仍需确认。本次保留违例，不通过大范围false path掩盖结果。PHY就绪信号已分别同步到RX/TX域，MAC TX复位已同步释放。

## 验证与复现

运动标定入口在 `code/fpga/acg720-motion-control/host/car_control.py`：轮径 `WHEEL_DIAMETER_MM=66.3`、有效轮距 `EFFECTIVE_WHEEL_BASE_MM=130.0`、左右编码器 CPR `1469/1471`。130.0 mm 是针对“90°落地转角不足”的首轮补偿初值，必须用实测角度继续修正；不要把它当作机械实测值。PI 正常目标归零时按 `ramp_limit` 减小输出，STOP/失联/故障仍立即关断。

22项上位机Python、50项原运动上位机Python、5项RTL测试通过。网络仿真覆盖完整Ethernet帧入口/出口、ARP、IPv4/UDP校验和、内部UART、ARM/速度/STOP、过期/异会话/错CRC/错来源拒绝，并由Python独立解码视频。摄像头初始化测试覆盖实际254项ROM写入、ID和9项回读；不模拟SCCB电气时序。RGMII接收使用Gowin官方IDDR模型检查对齐和ER。

在工程目录运行：

```powershell
python -X utf8 -B scripts/prepare_platform.py
python -X utf8 -B scripts/build_fpga.py check
python -X utf8 -B scripts/build_fpga.py build
.venv/Scripts/python.exe -X utf8 -B scripts/run_rtl_tests.py
.venv/Scripts/python.exe -X utf8 -B -m unittest discover -s tests -p 'test_*.py' -q
python -X utf8 -B scripts/package_firmware.py
```

编译超时默认1800秒，可用 `--timeout` 覆盖；生成目录 `.local/gowin-board`。本机未连接真实摄像头、RJ45或电机，未验证协商、图像吞吐、丢帧率和实车距离/转角。
