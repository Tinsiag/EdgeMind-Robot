## 单位和实现约定

- 累计计数：signed32、AB 四倍频。两侧前进应统一为正，但顶层左 `invert=0`、右 `invert=1`，尚无串口方向参数。
- 速度：mm/s；10 ms 窗口。换算为 `abs(delta) × diameter_mm × 3142 / (CPR × sample_ms)`，32 拍整数除法后恢复符号；3142 近似 pi×1000。中间值最后截取 32 位，尚需溢出范围检查。
- PI：固定 `Kp=1`、每次更新 `Ki=1/16`；已统一有符号运算和条件积分抗饱和；控制速度范围裁剪到 ±32767，不能把 32 位接口当成全范围保证。
- PWM：幅值以 1024 为满量程；默认 PI 限幅 1000，不等同于 100% PWM。`00` 只禁止桥输出，不能证明车体机械瞬停。
- 转向：协议传 int32 mrad/s，当前实现仅使用低 16 位；轮距也截取 16 位。偏置用 `/2048` 近似设计公式 `/2000`，存在约 2.34% 的比例偏差；有符号偏置/限幅已修正。
- 旋转：协议角度为毫度。参数 ID 6 虽名为 `counts_per_degree_q16`，实际是**每毫度计数 Q16**；理论比例 `round(wheel_base_mm × CPR × 65536 / (360000 × diameter_mm))`。这是对称轮组初始值，左右不一致和打滑需实测修正。完成门限为两轮误差 ≤4 counts，实测速度绝对值 <20 mm/s。

## 控制修复与剩余边界

本次修复 PI 有符号斜坡/限幅，速度裁剪到 ±32767 mm/s 而非低位截断；输出限幅最多 1024，零目标/禁用清积分并输出零，条件积分防止向饱和方向继续累积。每轮仅在 armed、无故障且自身目标非零时启动无反馈计时；待机、零目标和编码器步进重置窗口。STOP/DISARM/故障取消旋转，清待提交目标，故障优先于同周期命令；旋转角度和速度锁存，不再受查询 payload 改写。HELLO 不再改变状态。

CLI 运动在串口仍打开时通过 finally 尝试 STOP，覆盖正常结束、Ctrl+C、串口错误、缺少匹配遥测和 FPGA 故障。ROTATE 只提交一次，0x05 独立心跳续期并查询状态，READY 表示旋转结束后退出；不重发原旋转。异常停止不能保证已断开连接上的 STOP 送达，TTL 仍是失联后备，00 为滑行而非机械急停。仅 Python 异常可执行 finally；进程被强杀/断电依赖 TTL。

仍未完成：命令版本/精确长度/参数非零与范围/重复序号检查；SET_WHEEL_SPEED 独立最大轮速限制；CLEAR_FAULT 清除累计非法计数；S0 复位同步释放；旋转误差单位与速度整定、计数溢出范围；桥 PWM 周期锁存与机械换向等待；电流/电压/碰撞保护。转向仍用 /2048 近似 /2000，尺寸整数化造成误差。仿真与编译不等于架空实板、堵转、失联停车和落地验收，不自动下载或运行电机。
