## 悬空/落地区分及同步纠偏修复（后续）

用户明确最新两次20cm/200mm/s分别为：第一次悬空，正常低速稳定结束，轮周残差约3.4/3.7mm；第二次落地，行驶中左右输出交替归零/再起动，最后右侧计数停在2672、faults=4。旧进度差超过8mm就停领先侧的逻辑，在有负载/滞后时会清掉该侧PI积分并反复追赶，与此次波动相符；不能把悬空通过扩展为落地通过，也未独立排除摩擦、供电和反馈问题。

现仅改上位机：同步进度增益4降为1，加相对轮速阻尼0.2，纠偏不超过共同目标的20%，变化速率不超过80mm/s每秒；只适当减领先侧，不额外加速另一侧；删除8mm单轮停启门控，运动目标仍保留40mm/s下限。到达单轮终点/共同撤输出、取消、故障仍允许设零，停稳后不自动补进，±5mm容差不变。50项Python回归通过，A723固件和减速参数不变，需关闭并重开源码GUI。此修复未实板验证。

## 具体变化

右轮PI仍用车身前进为正的目标和编码器反馈，只在PI之后交换右桥两个IN的逻辑输出。正轮速命令应驱动物理前进；不是反相编码器或只把GUI目标反号。左桥及现有球号保持。1kHz、50%默认PI限幅、每10ms目标斜坡50、CPR1469/1471、整数轮径66/66、轮距121、最大差速速度400、旋转比例491沿用；上电DISARMED，目标/PWM0。

A722的非法AB停车屏蔽沿用，非法转换不计步；250ms默认运动命令TTL、约200ms无反馈、STOP/DISARM/S0继续有效。50%为可被参数9修改的默认限幅，直接轮速命令尚未独立限速。未修复的编码器噪声仍可能影响结果。

新增只读 `GET_CAPABILITIES=0x40` → `0xC0`，8字节载荷 `EVM1 + flags:u16(1) + max_speed:u16(400)`，小端。flags只有bit0“桥极性已修正”，未声明视觉能力。新版GUI识别后自动关闭主机右轮补偿、开启同步行程模式，视觉按钮保持禁用。旧GUI不会识别此标识，仍可能二次反相，**A723必须配合本次源码GUI使用**。

## 同步停止控制

系统已有FPGA内100Hz双轮PI速度内环；新增主机编码器行程外环，无IMU，不是外部航向闭环。主机约每40ms加串口耗时读取状态并续发轮速：

1. 以各轮CPR换算到轮周毫米，再按目标归一化进度比较，并结合两轮沿目标方向的速度差作阻尼。只以不超过共同目标20%的幅度平滑减慢领先侧，纠偏变化速率限制80mm/s每秒；行驶中不再因超过8mm差距而清零单轮目标，也不发送反向纠偏。
2. 两轮使用共同的剩余行程减速包络，初始规划减速度250mm/s²，最低运动目标40mm/s。使用速度、60ms估计延迟、800mm/s²估计滑行减速度预测撤输出距离。这些是待标定初值，不是实测制动保证。
3. 撤目标后继续零速度帧与查询，要求两轮遥测绝对速度<20mm/s、相邻采样计数变化≤2，持续至少150ms。最多等待3秒；不会把刚到计数且还高速滑行当完成。完成时STOP并零限幅。
4. 停稳后的各轮剩余行程须在±5mm内，才报告进入容差；不再自动补进或反转。超容差/故障/超时报告失败并收尾停车。±5mm为轮周位置初始容差，不是车体距离/90°误差保证，打滑仍不可观测。
5. 低速机械卡滞仍可能触发faults=4，未通过屏蔽此故障维持动作；需实车调最低可持续速度/摩擦/前馈。STOP为00滑行，没有新增主动制动。

## 使用步骤

1. VM物理断开、车轮架空，SRAM Program下载本文件，Programmer独立回读A723。掉电配置丢失。
2. 关闭旧GUI/串口工具。在运动工程目录启动**更新后的源码**：

```bat
python host/car_control_gui.py
```

3. COM4（或实际口）连接，界面应显示“右桥已修正 · 双轮同步减速”，反向补偿自动取消；不会开启视觉。连接仅停车，不运动。若没有该识别提示，先不发动作，检查所刷位流和GUI来源。
4. 接VM、架空测试前进10cm/200mm/s，确认两轮物理前进、计数同为正，再验后退与短角度。每次记录错误及末段轨迹；降低轮速可减少惯性，但过低可能不能持续转动，不盲目提高上限。
5. 方向通过后在平整地面短距离测试。比较停稳后的左右行程与实物角度，再标定有效轮径/轮距和滑行参数。仍需处理万向轮阻力与编码器信号质量；不能保证本次直接达到90°。

旧A722保留原固件/GUI兼容路径，新GUI默认不勾旧补偿，连接旧A722时需手动勾选。不要用旧EXE配A723，也不要把勾选当作所有固件通用设置。命令行serial_control.py仍是限时速度命令入口，没有主机同步位置外环；同步模式位于car_control.py和synchronized_motion.py。
