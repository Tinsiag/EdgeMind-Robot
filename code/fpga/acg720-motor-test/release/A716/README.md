# A716 50 kHz / 80% 构建及下载快照

2026-10-10 根据用户“直接上50kHz”的要求构建。沿用 A713 控制器，显式设置 50 kHz、80%，400 ms 爬升；S1/S2 独立持续启停，再按一次停止，允许同时运行，S0 停止两轮。默认停止，长按不会重复，无自动超时。

仿真通过，每 1 ms 检查 50 个 PWM 上升沿和 80% 高电平，并覆盖独立启停及 S0。21 个实际管脚和 50 MHz 时序核对通过，setup/hold 违反为 0，Fmax=188.257 MHz。SRAM 下载后独立读取 User Code=`0x0000A716`、Status=`0x70022020`。实际启停、噪声及转速变化仍待用户观察，不记录提速已经通过。

位流 `acg720_motor_toggle_50khz_80.fs`，SHA256=`9C85F5250EF1EF790036797F47320E03269E792131773B30437A78106287890B`。同目录保留原始构建、仿真、实际 PNR/时序、源码哈希及下载/回读记录，Git 不转换其字节。
