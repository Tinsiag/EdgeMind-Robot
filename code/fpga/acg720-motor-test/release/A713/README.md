# A713 持续启停构建与下载快照

2026-10-10 根据用户要求，将 S1/S2 改为左右轮独立持续启停，再按一次停止，允许同时运行；最高占空比提高为 65%，PWM 为 1 kHz，启动爬升 400 ms。默认停止，长按不会重复翻转，S0 停止两轮。没有单次超时。

仿真、实际引脚和时序检查已通过，SRAM 下载后独立读取 User Code=`0x0000A713`、Status=`0x70022020`。用户回复“都可以了，再调快点，调到80%”，确认左右持续启停正常。没有量化转速、电流或长时间负载数据；后续 80% 为 A714。

位流为本项目独立 RTL 构建的 `acg720_motor_toggle.fs`；SHA256=`A144E8D407B4D39044E1852272FFC0E007B97EFCCD6E736DA8F3A85F61831307`。同目录包含实际 PNR/时序报告、五个构建输入的哈希、仿真日志、编译日志、下载和独立回读日志。Git 保留其原始字节。

仅操作 SRAM，断电后丢失；未修改外部 Flash。LED 含义及使用步骤见 [工程 README](../../README.md)，实现及定位过程见 [排查与实现文档](../../MOTOR-IMPLEMENTATION-2026-10-10.md)。已实测可启动的短时 A712 快照见 [A712](../A712/README.md)。
