## 如何测试

1. **先通过维修后电气检查和新引脚 P&R 审查，未通过时不执行以下上板步骤。** 车轮架空；FPGA、电机 VM、编码器/参考端供电分开核对后共地。暂不沿用从 FPGA 3.3 V 给外部板供电的历史方案，不用已维修 FPGA 试探外部短路。
2. 下载本工程的 SRAM 位流后，先松开 S1、S2。约 100 ms 初始化及 20 ms 松键确认后可以开始。默认四个电机 IN 都为 0。
3. 当前 A717 下，按 **S1** 开始左轮占空比循环，松开后再按一次停止；**S2** 同样控制右轮。观察至少 12 秒可覆盖一轮；开始时为 0%，低占空比阶段可能不转，D1/D2 仍表示循环已开启。到 100% 时 D6 亮，随后占空比回到 0% 继续。两轮独立，允许同时循环；每次重新开启均从 0% 开始。
4. A713～A716 的历史版为固定最高占空比的持续运行，同样按键启停。**持续运行及循环版都不会自动超时。** 若使用历史 A712，则每次约 1 秒自动停止；A710/A711 为 2 秒。
5. **S0** 随时停止并复位。停止状态为 IN1=IN2=0，电机滑行，机械惯性不会由本程序立即消除。
6. 看电机是否旋转、对应的运行 LED 是否亮，以及编码器活动 LED 是否亮。转向暂不定义为车身“前进”，需要结合实际安装方向确认。

S1/S2 使用 20 ms 防抖；A713～A717 每键必须先稳定松开才允许下一次有效按下，长按不会反复启停，按住上电或释放 S0 不会自动启动。A710～A712 同时按下会拒绝启动，持续版及循环版则允许同时切换两轮。各版均不自动换向。

## LED 定义

这套灯态与原摄像头/DDR 自检不同。

| 灯 | 含义 |
| --- | --- |
| D0 | 启动延时结束，系统运行；是否允许启动还取决于按键是否已松开 |
| D1 | 左轮运行/循环已开启，期间常亮；A717 的 0% 阶段也亮 |
| D2 | 右轮运行/循环已开启，期间常亮；A717 的 0% 阶段也亮 |
| D3 | 左编码器 A/B 至少出现一次跳变，保持到下一次测试或 S0 |
| D4 | 右编码器 A/B 至少出现一次跳变，保持到下一次测试或 S0 |
| D5 | A713～A717 为两轮均停止；历史 A710～A712 为测试定时结束，不表示验证通过 |
| D6 | A717 为任一轮当前达到 100%；A713～A716 保留且灭；历史 A710～A712 为同时按键拒绝标志 |
| D7 | 1 Hz 心跳，每 0.5 秒翻转 |

编码器活动灯不代表转速、方向、四倍频计数或完整线序已经验证。复位后先建立采样基线，静态高电平不会被当成活动。持续版启动某轮只清除该轮活动记录，历史 A710～A712 开始一次测试时两侧都清零。停止后也可以手转电机检查活动。

## A710 默认实现及公共控制逻辑
