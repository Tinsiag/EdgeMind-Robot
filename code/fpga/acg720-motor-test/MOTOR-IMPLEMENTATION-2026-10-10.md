# ACG720 电机启动排查与实现

记录日期：2026-10-10。硬件为小梅哥 ACG720 / GW5AT-60B、用户现有嘉立创 EDA 电源板、AT8236 模块及 MG513 编码电机。

## 结果与证据范围

A712 已解决本次短时测试中电机不转的问题。程序为 1 kHz PWM，启动爬升至最高 50%，单次一秒后停止。下载及独立回读得到 User Code `0x0000A712`、Status `0x70022020`。用户在 S1/S2 逐轮测试及 D3/D4 观察提示后回复“转了，亮了”。

这条反馈确认电机能够启动、FPGA 能检测到编码器活动。未提供逐轮转速、方向、A/B 波形或脉冲数，不能将其扩展为编码器两相完整验证、闭环调速通过或整车落地运行通过。所有实物观察均来自用户，工具负责构建、引脚审查、下载及寄存器回读。

当前板上已更新到 A717 占空比循环版，频率为 50 kHz，按 0% 到 100% 每 500 ms 增加 5%，回到 0% 重复。S1/S2 各自启停，S0 停止两轮；下载及独立回读通过，实物循环表现待用户确认。下面保留各次对照结果，A717 实现详见末节。

## 如何定位本次不转的问题

| 版本 | PWM | 爬升至最高占空比 | 时限 | 用户实物反馈 |
| --- | --- | --- | --- | --- |
| A710 | 20 kHz | 10% → 15% → 20% → 25% | 2 秒 | 两轮均不转，编码器灯未亮 |
| A711 | 1 kHz | 10% → 15% → 20% → 25% | 2 秒 | 两轮仍不转，S1 时能听到声音 |
| A712 | 1 kHz | 10% → 25% → 40% → 50% | 1 秒 | “转了，亮了” |

首先检查供电、实际接口方向和六针线序，避免将运行 LED 当成驱动验证。D1/D2 亮只说明控制器进入运行状态，D5 亮只说明定时结束；它们不能证明电机收到功率。

A710 下，用户在电源板 L-1 测到约 0.8 V，与 3.3 V、25% PWM 的直流平均值相符。电机两端最高只读到约 0.05 V，模块 AIN1/AIN2 又未测出电压。这些读数存在短窗口及万用表平均测量的局限，不足以断定驱动损坏或模块输入完全无信号。已确认测量的是右侧、L 上方的左轮模块。

随后保持最高占空比 25%，仅把 PWM 从 20 kHz 改为 1 kHz。单个高电平从 12.5 µs 增至 250 µs，但电机仍不转，说明仅降频没有解决本次问题。A712 保持 1 kHz，并提高爬升阶段及最高占空比至 50%，对应平台高电平 500 µs，用户确认转动及活动灯亮。测试时限同时缩短至一秒。

这个对照支持此前低占空比下启动激励不足，提高启动占空比是本次有效的实现调整。尚未测量桥输出波形、电流、限流设置、摩擦或负载，不能指定其中某项为唯一根因；也不能认定 50% 是最低启动值。当前控制器不依赖编码器反馈允许启动，因此此前活动灯不亮不会阻止 PWM 输出。

## RTL 的具体实现

公共控制器为 `rtl/acg720_motor_test.v`，A712 包装顶层为 `rtl/acg720_motor_test_start50.v`。板载时钟 Y18 为 50 MHz，不使用 PLL、DDR 或摄像头 IP。A712 设置 `PWM_HZ=1000`、`DUTY_PERCENT=50`、`RUN_MS=1000`；一个 PWM 周期为 50000 个时钟，50% 平台为 25000 个时钟。

启动后的前 50 ms 为 10%，50～100 ms 为 25%，100～200 ms 为 40%，之后为 50%，到约 1000 ms 结束。独立 1 ms 时基控制按键防抖、松键确认和运行时限。没有自动重试或根据编码器缺失继续加大占空比的行为。

每台电机使用 AT8236 A 通道的双 IN 接口。一个方向的输入为 IN1=PWM、IN2=0；停止为两个输入都低，电机滑行。此处桥输出方向尚未映射为整车前进，不套用旧 TB6612 固件的独立 PWM/STBY 接口。

S1 只选择左轮，S2 只选择右轮，同时按下拒绝启动。启动前必须两键稳定松开，按住上电、按住复位释放或按住超过时限不会自动启动或重复。S0 低电平异步清除控制状态并门控物理 PWM 输出，释放经同步及启动延时后重新等待松键。

编码器四路经过两级同步，先建立静态基线，再检测任一 A/B 跳变并锁存到 D3/D4。开始新测试时清除两侧历史活动。该实现没有正交解码、四倍频计数、转速计算或 PID。摄像头复位保持低，独立测试位流暂时替代摄像头 SRAM 程序，摄像头与 DDR 源码保留。

## A712 实现边界

通过的是手动、架空、单轮、短时启动及编码器活动测试。当前最高 50% 是经本次实物验证的参数，尚未验证长时间负载、电流、车身前进方向、速度闭环或摄像头与电机同时运行。

本次只写 SRAM，没有修改外部 Flash，断电后 A712 丢失；重新供电将运行 Flash 原有程序，若要继续该电机测试须重新下载 A712。后续闭环实现应先确认各轮方向及编码器 A/B 计数，再增加速度计算和受限的 PID 输出。

## 用户后续要求的持续运行版 A713

A712 启动通过后，用户要求按 S1/S2 分别让左/右轮持续转动，再按一次停止，并提高速度。A713 使用新文件 `rtl/acg720_motor_toggle.v`，保留 A712 构建快照。按键防抖后检测有效按下事件，每个事件只翻转对应轮的运行位；另一轮状态独立，允许两轮同时运行。每键在配置、S0 或前次事件后必须先稳定松开，长按不会重复翻转。

去除单次超时，以两个独立且饱和于 400 ms 的爬升计数器控制启动占空比。前 200 ms 沿用 10%→25%→40%，200～300 ms 为 50%，300～400 ms 为 60%，之后为 65%。两轮共享 1 kHz 周期计数，分别比较各自占空比。再次按键将对应运行位清零，立即门控为低；S0 直接门控两路 PWM 并异步复位。停止为 IN1=IN2=0 的滑行，不是机械瞬停。

编码器同步和活动基线延续原实现，启动某轮时仅清除该轮活动记录。D1/D2 是左右运行状态，D3/D4 是活动记录；D5 改为两轮都停止，D6 保留且灭，D7 仍为心跳。该实现为开环持续驱动，65% 不等同于已测量的转速；尚未加入转向切换、速度反馈控制、电流测量或摄像头合并。

专用仿真已覆盖配置时按住两键、防抖、准确 65% 周期、持续超过原两秒时限、第二次按下停止、长按不会重启、另一轮继续运行、同时切换两轮、编码器历史独立清除及 S0 在时钟边沿间停止。编译和下载的实际结果另记于工程 README 的 A713 完成记录。

A713 已完成 Gowin 编译、实际 21 个管脚核对和 50 MHz 时序审查，setup/hold 违反端点为 0，Fmax=184.374 MHz。SRAM 下载后独立回读 `0x0000A713`、Status=`0x70022020`，未写 Flash。位流及原始证据放在 `release/A713/`；SHA256 为 `A144E8D407B4D39044E1852272FFC0E007B97EFCCD6E736DA8F3A85F61831307`。用户回复“都可以了，再调快点，调到80%”，确认左右持续启停正常；没有提供量化转速或负载数据。

## 频率对照 A715

A715 保持 80% 和同一持续启停逻辑，将 PWM 从 1 kHz 改为 20 kHz。AT8236 原厂手册允许至 100 kHz 输入，本次 20 kHz 在其范围内。原先 A710 的 20 kHz/25% 不能启动，与现在 20 kHz/80% 的对照条件不同，不能据此前结果预判 A715。

当前 IN1=PWM、IN2=0 是快衰减方式。频率和衰减会改变绕组电流建立及关断过程，但调整频率不能直接按比例提升转速，80% 占空比也不等于电机达到额定转速的 80%。VREF/检流电阻可能限制电流，VM 可能在负载下变化；这些因素尚未测量，不作为已确认原因。参考来源及构建细节见工程 README 的 A715 节。

仿真以 `TOGGLE20K80_TEST` 实例化 20 kHz/80% 包装顶层，同时统计每毫秒上升沿数和高电平数量，确认实际频率和占空比；保留持续启停、两轮独立及 S0 测试。后续如需判断实际加速，应使用编码器计数得到同一工况下的脉冲率，当前 D3/D4 活动灯不提供该数据。

A715 仿真及编译完成后，用户在下载前要求“直接上50kHz”，因此 A715 没有下载，不记任何实板结果。

## 按键控制占空比循环 A717

用户在 A716 下载后改为要求从最低到最高占空比循环，并保留按一次开始、再按一次停止。A717 使用独立顶层 `rtl/acg720_motor_sweep.v`，保持 50 kHz，默认 `STEP_PERCENT=5`、`STEP_MS=500`。左右各自保存循环开启位、当前占空比门限和本档毫秒计数，周期计数器由两轮共享。

50 MHz / 50 kHz 得到每周期 1000 个时钟，每 5% 对应 50 个高电平时钟。某轮有效启动时清零该轮门限及计时，第一档为 0%；每 500 个 1 ms 时基事件增加 50，到 1000 后保持一档，再清零并重复。共 0%、5%、……、100% 的 21 档，一轮约 10.5 秒。新门限在 PWM 周期边界锁存生效，避免中途变更比较值产生不完整脉冲。100% 的比较门限为 1000，计数范围为 0～999，故始终为高；0% 始终为低。该门限使用能表示 1000 的 10 位，加法先保留进位，再截取合法范围，最后增加是 950+50，不会越界。

S1 只切换左轮、S2 只切换右轮，两轮可同时开启且循环进度独立。停止时对应运行位门控物理输出为 0，下一次开启从 0% 开始。沿用稳定松键确认、防抖、长按只触发一次、S0 异步停止及编码器活动采样；启动某轮只清除该轮活动记录。D1/D2 在 0% 档也表示循环开启，D5 表示两轮都停止，D6 在任一轮实际占空比门限达到 100% 时亮。电机仍采用 IN1=PWM、IN2=0，一个桥方向，停止为滑行。

专用仿真保持输出为真实 50 kHz，将测试时钟设为 5 MHz，以每周期 100 个时钟精确表示所有整数百分比。为了加速，将每档改为 4 ms、防抖为 2 ms，逐档统计高电平数量及上升沿。验证左轮两轮完整循环、右轮完整循环及回绕，所有 21 档均匹配，0% 无脉冲、100% 无低电平；另覆盖独立启停、重新从 0% 开始、按住不重复、短暂抖动、另一键保持按下时的启动锁定、编码器历史独立清除以及 S0 在时钟边沿间立即停止。实际编译顶层仍使用 50 MHz、500 ms 和 20 ms。

Gowin V1.9.12 编译和实际 21 个管脚审查通过；50 MHz setup/hold 违反端点均为 0，Fmax=184.331 MHz。下载前读取 `0x0000A716`，operation_index=2 SRAM 下载完成后独立读取 `0x0000A717`、Status=`0x70022020`。位流及原始证据放在 `release/A717/`，SHA256=`B54E13D91CA2C3A3F0A788FA0ACB1AB27E2A2DB854872CBFF902E770F6D48BC7`。复现命令及完整使用方法见工程 README 的 A717 节。
