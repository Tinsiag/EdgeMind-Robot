## 实际行为和修改

- 从交接的 `acg720_bridge_probe` 复用按键去抖、上电持键锁止、单轮选择、超时和释放重新允许逻辑；不改 A71A 独立空载固件。该模块在 A71B 中只提供内部使能，静态输出不直连电机。
- 物理 IN1 为 1 kHz PWM，IN2 恒低；0～50 ms 为 10%，50～100 ms 为 25%，100～200 ms 为 40%，200～1000 ms 为 50%。PWM 比较直接作用于计数器，使第一个完整周期也具有准确占空比。
- S1 只驱动 L1/2=A18/A19，S2 只驱动 R5/6=F13/F14。松键、S0、双键立即撤销驱动，不等去抖；最长 1000 ms，即使 RUN_MS 请求更长也裁剪到 1000 ms。超时持键不重复，必须两键稳定松开才能重试。
- 停止输出为 00，桥为滑行，机械轮子不保证瞬时停住。本版没有 VM、电流或电机插头检测。
- D0=初始化完成；D1/D2=左/右驱动使能；D3/D4=本次单轮测试期间累计四次合法 AB 跳变锁存；D5=超时；D6=双键拒绝；D7=心跳。D3/D4 每次新尝试清零，静态高电平和双位非法跳变不触发。跳变不等于方向/速度/车轮运动验收。
- `camera_reset_n=C14` 继续保持低；没有 UART 控制，不修改闭环 PI/机械参数。

源文件 `rtl/acg720_motor_hold_1khz_50.v`，工程 `acg720_motor_hold_1khz_50.gprj`，入口 `build_hold50.tcl`，审查变体 `hold50`。

用户随后按继续 VM 断开、同一模块 AIN2（R 六线排第6脚来线）对 GND、单次 S2 且 D2 亮时读取的要求，反馈“没有电压”，记录约 0 V，未给出数值精度。与前次 AIN1=1.6 V 合看，输入直流读数与当前程序预期相符；两次非同步、且 VM 断开，不证明带 VM 的输入波形和桥输出正常。
