## 固定行为

独立顶层 acg720_gpio_static，User Code 0xA719，保留A718/闭环产物。50MHz，无PWM、UART或速度控制。上电100ms初始化、20ms去抖，配置或复位时按住键不得输出，必须先全部松开稳定20ms才允许。

- 无键：左IN1/2均低。
- 单独按住S1(A20)：左IN1(A18)高，左IN2(A19)低；去抖后维持，松键原始信号直接门控低。
- 单独按住S2(B20)：左IN1低，左IN2高；这里S2不是右轮控制！
- 同时按键立即全部低，且必须全部松开重新允许；S0(F15)异步禁止，释放后重新初始化/松键允许。
- 右IN1/2(F13/F14)始终低；camera_reset_n(C14)固定低。
- LED D0=初始化释放，D1=左IN1逻辑高，D2=左IN2逻辑高；D3=左A、D4=左B、D5=右A、D6=右B的同步实时电平，非故障/活动锁存；D7心跳。LED不是引脚电压测量。

沿用现有CST全部21端口与新接线、LVCMOS33，不改变物理Bank供电。无新false path/时钟放宽。
