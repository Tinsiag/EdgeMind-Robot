- 直线：编码器轮速PI + IMU相对航向纠偏。距离任务更新速度/减速时保持起始航向；停车后下一动作锁存新航向。
- 原地旋转：FPGA相对航向闭环，支持正负1至360度、跨±180度、减速和静止判定；静止后误差超过5度报告故障，不自动补转。
- 弧线：上位机用实测234 mm轮距换算左右轮速并统一限幅，同时积分同一限幅后的期望角速度；FPGA依据期望航向和IMU实测值限幅纠偏。大角度弧线按住运行、松开停车；不是带指定终点角度的自主路径规划。
- 保留250 ms命令租期、UI按住租期、STOP、取消、IMU失效、编码器无反馈保护；运动命令不自动重发。ToF未接入，本变体没有前向避障保护。

新增内部命令0x47，载荷为左右轮速int32及期望原始IMU航向int16，共10字节，小端；与0x45采用同样的航向纠偏及限幅。0x400能力位表示支持此扩展，沿用EMC1和A741编号。0x47无应答，必须持续更新，超时停车。陀螺仪积分航向存在漂移，Z轴需垂直地面，安装方向由配置imu_yaw_sign决定。

## 使用

### 当前改动（2026-10-22）

- GUI 日志支持 `ALL/INFO/DEBUG/WARNING/ERROR` 筛选；完整分级记录仍写入 `session.jsonl`。
- 左右控制按钮为“按住原地左转/按住原地右转”，左右轮目标符号相反；前进/后退保持长按控制，定距前进/后退独立执行距离任务。
- 低速 100 mm/s 时曾出现 `faults=0x0004`，而400 mm/s较少出现。该故障来自编码器无反馈保护，当前将反馈观察窗口从500 ms延长到1000 ms，仅减少起步阶段误判，仍会停车保护；尚未证明电机/编码器硬件根因已消失。
- 2D地图支持导出反向轨迹 JSON，用于后续路线跟踪；当前版本只导出路线，不自动控制小车返程，也不包含定位/导航执行器。

### 详细日志

每次启动上位机会在 `a741-imu-motion/.local/logs/YYYYMMDD-HHMMSS/session.jsonl` 创建会话日志。完整 `telemetry` 记录包含 FPGA 时间/序号、状态、故障码、左右目标轮速、实测轮速、编码器计数、PWM、IMU 航向/角速度、传感器错误计数、网络桥状态/坏FCS、UDP请求回复/超时、雷达缺包及视频完成/丢帧。窗口底部同时每约250ms显示一行 `TEL` 摘要，便于观察运动过程；遇到故障请保留故障前后至少10秒日志，不要只截取最后一行。

日志事件包含 `level`：`INFO`（连接、动作和结果）、`DEBUG`（高频遥测）、`WARNING`（短时UDP超时、未确认状态或可恢复故障）、`ERROR`（任务失败或安全停车）。短时UDP超时不再自动销毁视频/雷达/遥测连接；只有明确断开、关闭窗口或不可恢复初始化错误才会清理连接。

连接完成后，上位机自动执行一次IMU诊断及静止校准，不自动ARM或运行电机。连接前请固定模块、水平放置并保持车体静止；失败时保持连接，按提示排除姿态/采样问题后手动校准。无需每个动作前点击IMU诊断；重新连接下发参数或IMU失效后须重新校准。当前速度上限400mm/s，GUI界面、运行前检查及连接时下发的FPGA标定参数共用此值。手工输入越界值在GUI提交前提示，不因普通参数错误断开控制。

FPGA ARM因锁存故障拒绝时保持上位机连接，不自动清错或重试。`faults=0x0004`表示编码器无反馈保护；先检查编码器线束、车轮是否受阻，再按“清除故障”，GUI会复查FPGA故障位。仍有故障时不允许运动。
