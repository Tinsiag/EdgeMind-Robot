## 修改

- 仅在电机锁定IMU测试模式下启用ALLOW_MPU6500，严格识别0x68/0x70；未知身份继续拒绝。
- MPU6500使用专用ACCEL_CONFIG2=3并读回，保持±2g、±2000°/s、100Hz采样；身份不匹配也尝试另一个地址，避免错误回应遮蔽0x69上的目标。
- 上位机显示实际sensor_model与十六进制身份/地址；MPU6500温度使用raw/333.87+21；无效时三轴和温度为None，不展示默认值作为测量。
- 默认非测试驱动仍拒绝MPU6500且不写入该设备，未擅自放开完整运动路径。
- 19组RTL、15项Python通过：两型号/两地址、额外配置回读失败、未知身份拒绝、MPU6500线级I2C/采样/断流、默认路径拒绝、温度分支与无效值。

原厂资料入口：TDK产品中心MPU-6500的Register Map；原下载路径为 https://invensense.tdk.com/wp-content/uploads/2015/02/MPU-6500-Register-Map2.pdf 。本次其在线访问会跳转，原厂同文档可通过公开存档核对，文档号/版本与上述一致。

## 使用边界
