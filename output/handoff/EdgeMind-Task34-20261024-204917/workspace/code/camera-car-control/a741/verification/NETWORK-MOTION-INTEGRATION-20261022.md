## 功能边界

- 直线：等速左右轮目标、编码器轮速 PI 与 IMU 航向纠偏。当前距离任务会重复下发轮速；当前 RTL 每次收到轮速命令都重新锁存航向原点，因此不能把长距离航向保持精度当成已验证结果。
- 原地旋转：相对 IMU 航向累加、回绕处理、减速与稳定判定，支持正负设定角度。
- 连续弧线：主机按实测轮距 234 mm、线速度与角速度换算轮速，并同比限幅；轮速由编码器 PI 闭环。IMU 失效触发停车，但弧线尚无角速度跟踪闭环，也无指定总角度弧线任务。
- 电机硬锁解除后仍需配置、水平静止校准、有效 IMU、无故障及人工 ARM；保留 STOP、失联和无编码器反馈停车。ToF 未接入，无前向障碍停车保护。
