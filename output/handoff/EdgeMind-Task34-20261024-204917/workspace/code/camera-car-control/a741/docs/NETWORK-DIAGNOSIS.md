# A741 控制超时诊断

## 当前状态：2026-10-22

20261021-223907/234236 实验性 PHY 初始化位流已由用户报告冷启动无法连接、D2 不亮。恢复原厂 `phy_reg_config` 初始化路径，不再将实验性身份读取作为 MAC 启用条件；EMP1 在回退构建中禁用，receiver.phy=null 属于预期。下文 2026-10-21 的身份检查与 EMP1 说明是旧实验版本记录，不是当前顶层行为。旧版原厂访问等待不足手册 50 ms 的风险仍存在，此次仅恢复对照基线，不声称符合完整 PHY 上电规范或解决间歇性坏 FCS。

无法从 D2 不亮判断是 PHY 地址、身份、BMCR 或 MDIO 哪一项失败。地址与 Go 同拍赋值也未被证实为根因，不能当作已定位结论。停止使用上述实验诊断位流做运动验收；先用回退版在 VM 关闭时确认冷启动 D2、EMS1、STOP 和只读查询。

## RTL8211F-CG 手册核对（2026-10-21）

本工程使用用户提供的 `RTL8211F(I)-CG/RTL8211FD(I)-CG Rev.1.4` 数据手册，不再把 RTL8211E/EG 资料当作本板 PHY 的寄存器依据。手册明确：`PHYRSTB` 低电平至少 10 ms，释放后至少等待 50 ms 才访问寄存器；`PHYID1` 应为 `0x001c`，`PHYID2` 的 OUI/model 匹配 `0xc910`（修订位可变化）；页面选择使用寄存器 31 的 12 位值。

手册将 `0xd08/0x15` 的 bit6 定义为 RGMII in-band CRS，未公开定义 bit3 为 RXDLY 软件控制位。RXDLY/TXDLY 在本手册中是上电绑带脚（分别为 PHY pin 25/24），上拉表示增加约 2 ns。当前初始化因此只做硬复位、身份和 BMCR/BMSR 只读诊断，不写 `0xd08/0x15` 保留位，也不强制重启自协商；是否存在板级延时绑带及其电阻必须以 ACG720 第 6 页原理图和实物核对。

新增 `EMP1`（32 字节）诊断包，每秒发送一次，包含 PHY 地址、复位/等待参数、PHYID、BMCR、启动时两次 BMSR 读取、ready/error/fault。`bmsr_current` 仅为启动流程的第二次读取，不是实时链路状态；`ready` 表示初始化身份/状态检查完成，不表示网线链路正常。它独立于 EMS1/EML1，不改变 112 字节遥测格式。旧客户端不理解 EMP1，可能记录未知包错误，诊断时必须使用本次更新后的客户端。公开手册未定义 bit3 不等于芯片一定不支持该位；本次不据此推断真实硅片实现。

2026-10-21现场表现：连接可通过部分请求，随后0x44读取参数及STOP超时；雷达/EMS1继续发送。不能据此断言RGMII、控制桥或电脑网卡中的某一个已经确定故障。

## 现场操作

1. 保持电机VM关闭，关闭上位机，释放UDP 5001和6103。
2. 刷入包含网络诊断扩展的独立新构建后，运行本目录上一级的 `diagnose-control.cmd`。不需要先在GUI连接。
3. 脚本先等待遥测，再只发送一次STOP。建立会话成功才发送最多100条只读参数查询，间隔50ms；不写配置、不ARM、不运行电机、不自动重发STOP。
4. 输出目录为 `.local/control-debug/日期-时间`，`events.jsonl`保留请求、耗时、回复、诊断和遥测；`summary.json`统计成功/失败。STOP失败时脚本结束，避免连续尝试掩盖问题。

## 判断依据

- `fpga_network.supported=false`：目前运行的固件没有诊断字段，不能用保留位判断。
- STOP前后坏FCS计数增加：FPGA的MAC确实丢弃过CRC坏帧。需继续核对RGMII接收时序、PHY延时及线路；不能直接推断是哪一项。
- 有效接收帧计数变化、桥拒绝计数变化：协议过滤或内部串口回复异常需进一步排查。
- 桥长时间停在REPLY：正在等待内部运动模块串口回复；TRANSMIT则在等待网络下行接受回复。单个50ms采样不能代表所有短暂状态。
- 模16计数可能回绕、有效帧含ARP，未变化不能独立证明请求未到达。
- 网口good-frame/坏FCS计数由MAC跨域同步后在50MHz逻辑域累加，没有增加跨域多位直采。

目前RGMII约-1.2ns hold违例来自初始外部时序预算，尚未核对真实PHY发送延时和板级时序。它是风险线索，不能当作已证实的故障结论，也不能通过删除约束消除。新诊断位流不宣称通信故障已修复，时序与实板均须继续验收。
