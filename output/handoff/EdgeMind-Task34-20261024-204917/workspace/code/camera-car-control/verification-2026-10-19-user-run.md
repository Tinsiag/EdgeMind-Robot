# 2026-10-19 实板运行摘要

## 后续角度标定

第二轮用户反馈：260.0 mm参数下，指令90度实际约100度。按 `260 * 90 / 100 = 234.0 mm` 更新上位机有效轮距，待同速度、地面和载荷下左右转分别复测。两轮均为目测近似值，不代表角度精度已验收。

用户反馈指令90度、目测实际约45度。假设测试使用130.0 mm有效轮距且动作正常完成，上位机有效轮距暂按 `130 * 90 / 45 = 260.0 mm` 调整。该值是转向补偿参数，不是机械轮距测量值；需重启上位机后分别复测左右90度。若测试发生故障、通信中断或提前停止，该次角度不适合作为比例标定依据。直行参数与固件未因本次标定修改。

来源：用户提供的上位机运行日志。

- 网口控制能够连接。
- 前进、后退、左转、右转和停止均观察到实际动作。
- 多次短距离动作显示“动作完成”。
- 部分长动作报告 `state=3, faults=4`，触发无反馈保护。
- 多次出现“串口没有匹配回复”，属于控制链路回复超时，需要继续检查通信稳定性。
- 运行中行程误差约从数毫米到二十多毫米不等，减速参数和编码器反馈仍需标定。

该摘要记录实板行为，不代表已经完成时序签核或长期可靠性验收。

历史软件修改曾将有效轮距设为130.0 mm，之后260、当前234 mm。轮径和CPR虽新增显式常量，仍有其他重复配置；PI目标归零递减按FPGA时钟运行，没有实现预期的平滑停车。不能将这次修改写成问题已解决，详见 [当前状态](CURRENT-STATUS.md)。
