# ERR0001：负载相关停车诊断

2026-10-31。用户确认FW74505可前进、可转弯，随后报告平地直行时突然FAULT/ERR0001，按S1可再启动。最新澄清为架空正常、落地触发；这替代将较早组合选项答复解释为“架空必现”的假设。不能直接将重量当成错误码的原因。

旧版ERR0001为IMU航向无效、原始采样无效、倾角无效或超过22.5度的合并错误。旧版没有事件锁存，恢复后的正常角度不能证明触发瞬间没有超倾角或无效样本。首次记录只到CALIBRATE，第二段900个状态均为FAULT0001，未捕到进入FAULT的边沿；总线错误0、样本年龄0～10ms，故障后的倾角最大约7.21/8.78度。不能将它写成已捕获根因。

FW74506为诊断增量，不改变停车条件和倾角阈值。在触发ERR0001的同一时钟锁存原因、有效标志及roll/pitch，直到下一次S1才清除。新遥测仍只有TX，不新增ARM或配置接收。

EMS1长度112不变，26字节为锁存原因，27字节为当时标志。EMF1长度48不变，42字节原因，43字节标志，44..45为有符号roll、46..47为有符号pitch，单位为Q15半周；32..35为当前IMU驱动诊断。旧版这些保留位为零，只有实际revision≥74506时才能解释新含义。

原因位0..3分别为航向/IMU无效、原始gyro采样无效、倾角无效、超倾角。校准超时另用bit4表示未静止、bit5表示未校准。标志位0..7分别为IMU有效、原始gyro有效、倾角有效、超倾角、静止、CPU正常、雷达流有效、完整扫描有效。

IMU驱动诊断低7位为I2C地址，8..15为WHO_AM_I，16..23为驱动故障码，24为ready，25为stationary，26为sample_valid。样本时间和错误数仍来自EMS1的64..67、76..79，序号100..103。

`capture_imu_fault.py`仅接收UDP6103，记录上述内容与实际revision。新测试imu_fault_latch_tb验证各故障源区分、故障后数据恢复不会覆盖、当时角度原子锁存、S1清除以及原有立即撤销电机许可。对应Gowin原语模型也执行该用例。

后续在VM关闭时烧录诊断版，通过健康后，受控平地短程复现一次，出现ERR0001后关闭VM，保留故障、不按S1；读取锁存原因后再修对应路径。若诊断尚未确认，不盲目提高倾角阈值、屏蔽IMU有效性或增加电机输出。
