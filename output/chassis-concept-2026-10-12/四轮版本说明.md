# 四轮底盘概念第二版

按用户本轮修正，后面两只轮分别由现有两台 MG513X 驱动，前面两只用被动万向轮支撑。前后轮没有同步带或链条联动。

本轮使用的电源板、荔枝派、MG513X 和 FPGA 机械文件已经收纳到 [项目模型目录](../../model/README.md)，可在克隆仓库并取得 Git LFS 文件后打开。

第一版 AI 效果图不具备严格的尺寸约束。第二版先将电源板、荔枝派和 MG513X 的实际 STEP 三角网格按毫米、缩放 1.0 装入确定的三维场景，再按该场景生成造型效果图。尺寸装配参考采用正交投影，保留模型真实几何；AI 效果图仍用于造型讨论，不能用于尺寸测量。

## 尺寸依据

| 项目 | 尺寸或位置，mm | 属性 |
| --- | --- | --- |
| 电源驱动板 | 包络约 100×50.06×18.30 | 原 STEP，缩放 1.0 |
| 荔枝派 | 包络 84.455×103.814×20.358 | 原 STEP，縮放 1.0，含接口伸出部分 |
| MG513X | 单台包络 64.5×57.6×38 | 原 STEP，缩放 1.0，两台位于后轴 |
| FPGA 板面 | 138.049×91.567 | V3 平面机械资料；板厚和器件高度是概念代理 |
| 电池 | 105×33×25 | 用户给定外形，纵向放置，下层中央 |
| 后驱动轮 | 直径 80，胎宽 18 | 拟选，没有对应实物轮模型 |
| 前万向轮 | 直径 50，胎宽 16 | 拟选，没有对应实物轮模型 |
| 主体板 | 260×180 | 新设计的概念轮廓 |
| 后轮中心 | 横向 ±106，纵向 +80，轴高 40 | 后为 +Y；电机轴指向左右外侧 |
| 前轮中心 | 横向 ±100，纵向 -95，轴高 25 | 前为 -Y；万向轮转轴略偏后形成拖距 |
| 上层托盘 | 板底 Z=64，厚 3 | 概念尺寸 |
| 板卡安装基准 | Z=76 | 概念尺寸 |
| 场景实际包络 | 长 260.5，宽 234，高 95.20083 | 正常装配状态，包含轮毂和护边；不含展开位移 |

前上层为 FPGA 参考板位，后上层为荔枝派；横向中心均为 0。两者板面前后约留 18 mm 间距。电源驱动板位于下层前部，电池位于下层中央，左右 MG513X 位于下层后部。前万向轮安装在前角外伸托架上，以便完整支撑并清楚显示四个轮子。

本次尺寸参考图验证了模型载入比例、基本放置和场景包络。安装支架、前万向轮扫掠、轮毂适配、FPGA 实物版本、孔位、线束净空和承载尚未完成 CAD 验证，不是可加工的底盘工程。

## 文件

- `chassis-concept-v2-four-wheel.png`：内置 imagegen 生成的造型效果图。
- `references/assembly-four-wheel-iso.png`：直接三维渲染的尺寸装配参考。
- `references/assembly-four-wheel-top.png`：正交俯视比例参考。
- `references/assembly-four-wheel-exploded.png`：原尺寸模型的分层展开参考。
- `references/four-wheel-dimensions.json`：三维场景的尺寸参数和计算包络。
- `four-wheel-generation-prompt.txt`：完整图像生成提示词。

旧版 `chassis-concept-v1.png` 保留作历史草图，以本说明所列四轮方案为当前概念。
