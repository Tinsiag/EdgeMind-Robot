# 用户要求的顺时针90度、长宽互换对照

位流`impl/pnr/probe.fs`，SHA256=`7b218658353e5aea6d0d1a5708862742a6b750aaad10c92864006bacad25168d`。

用户明确要求“方向搞反了，长宽对调了，你顺时针旋转90度试试”，并不再提供型号。本版遵照该要求进行诊断，不预判未确认型号的面板原生扫描方向。

| LED | 有效扫描 | 总扫描 | 图案 |
| --- | --- | --- | --- |
| D6灭、D7灭 | 800×480 | 1056×525 | 原八色块顺时针90度，再缩放至800×480 |
| D6亮、D7灭 | 480×800 | 525×1056 | 原八色块顺时针90度，宽高互换 |

两种状态33MHz、59.5238Hz，每480帧（8.064秒）切换，周期16.128秒。边界在整帧结束切换，不在有效画面中截断。长宽互换模式连同行场同步脉宽、起点、总量一起转置：H同步2、DE起点34；V同步128、DE起点215。它不是已获实物型号规格确认的480×800标准时序，只是本次用户要求的完整转置实验。不能由仿真/STA推定面板兼容。

正确图案为四列两行，上排黄、绿、红、黑，下排白、青、紫、蓝。相对于原图800×480，旋转坐标关系为源x=目标y，源y=479−目标x；800×480模式再按各轴缩放。独立仿真对两种模式各两完整帧的全部像素应用逆变换检查，而非仅验证颜色数量；还验证DE行宽、行周期、HS脉宽、帧周期、半周期建立间隔、PAD读回和电机GND。仿真PLL为理想33MHz，阶段周期缩为3帧；实际PLL保持官方原文件。

恢复官方DE/背光定义（AB22=DE、AB21=高），背光持续点亮；PCLK AB20、HS V19、VS Y19、所有RGB及电源接线保持。D0诊断标志，D1系统心跳，D2帧活动，D3背光PAD读回，D4像素时钟PAD活动，D5 DE曾活动，D6几何模式，D7灭。

布局1、布线1，时序驱动和hold修复，时序与SDF见`REVIEW.json`。最后编译无WARN/ERROR；初版`rotation-probe`的SystemVerilog端口初始化警告通过改用内部初始化寄存器解决，初版未烧录。v2全部复验。
