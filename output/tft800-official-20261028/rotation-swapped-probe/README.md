# 顺时针90度＋DE／背光交换对照

位流`impl/pnr/probe.fs`，SHA256=`2733c1ea9b04b421ff639bd8765ec90519c3738a56610cc2cf5f107fcf324912`。

前一旋转候选两种尺寸均白屏后，用户提出“是不是得交换 DE／背光”。本候选保持前一`rotation-probe-v2`的全部扫描/PLL/约束，只将DE输出送到AB21（用户J1-34），AB22（J1-33）输出恒高。未改电源、时钟、RGB、HS/VS或实际排线；不预判这是正确永久映射。

仍为D6灭时800×480内旋转并缩放、D6亮时480×800完整行场转置，每8.064秒切换，D7灭。正确图案四列两行：上排黄／绿／红／黑，下排白／青／紫／蓝。若AB21确实接背光，会受DE占空比影响变暗，D3可能较暗或看似常亮，这不是阶段标记。仅“固定但图案随机”不算通过。

独立仿真在两个尺寸中各检查两完整帧的每个旋转像素、DE行宽/行周期、同步脉宽、帧周期和PAD读回、电机GND；这次在AB21检测DE，AB22必须恒高。真实PLL参数保持原厂；仿真PLL理想33MHz，阶段帧数缩为3。

布局1/布线1，时序驱动、hold修复。setup+2.835、hold+0.183、MPW+7.122ns；recovery/removal无报告路径。SDF纳入AB21上的DE：setup15.2265、hold15.0305ns，按8ns接收要求+1ns未实测板/线预算+0.3ns时钟预留，余量5.7305ns。编译无WARN/ERROR。未测屏幕端信号。

暂不含摄像头/DDR/IMU/网口，主工程源码保留，四电机GND。当前硬件与观察以`output/flash-rotation-swapped-20261028/STATUS.json`为准。
