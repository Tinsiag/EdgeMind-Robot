4.2.14 OSIDES64 
Primitive Introduction 
OSIDES64 performs 1-bit serial input to 64-bit parallel output 
oversampling serial-to-parallel conversion. 
Functional Description 
Using two IOLs, 1:64 oversampling serial-to-parallel conversion with

adjust the order of output data is not supported.

parallel mode is that oversampling performs four samples in the same fclk 
cycle, while normal serial-to-parallel performs only two samples on the

270°.
