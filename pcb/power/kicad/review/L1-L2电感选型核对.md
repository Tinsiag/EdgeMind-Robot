# L1/L2 电感值与封装核对

2026-10-03。结论：**没有必须使用 4.8µH 的依据，建议以常见 4.7µH 作为每路 5V/3A 的选型起点。**
4.7µH 与 4.8µH 的标称差约 2.1%，远小于当前系列 ±20% 的电感公差。
µH 是电气参数，封装应按具体料号和厂家尺寸图选择；同一 MCS0630 外形可包含多个电感值。

## 当前工程中的冲突

- 原理图和 PCB 的 L1/L2 Value 为 `4.8uh`。
- 厂商料号为 `MCS0630-2R2MPY1`，采购编号 C2937096，实际标称为 **2.2µH**。
- 封装 `ProPrj_pow-easyedapro:IND-SMD_L7.3-W6.6` 已有焊盘，缺少的主要是实际 3D 文件；本次已补齐 0630 替代外形。
- 本次 3D 绑定保留电气字段。采购前必须使 Value、厂商料号、采购编号一致。

## 按当前电源指标估算

使用 MP2236 手册连续导通模式公式：

`ΔIL = VOUT × (1 - VOUT/VIN) / (L × fSW)`

取三串锂电满电 VIN=12.6V、VOUT≈5.03V、典型 fSW=600kHz。MP2236 是 COT 控制，表中为近似值，不能替代实测。

| 标称电感 | 电感电流纹波（峰峰值） | 3A 负载时峰值 | 4A 负载时峰值 |
| --- | ---: | ---: | ---: |
| 2.2µH | 2.29A | 4.14A | 5.14A |
| 4.7µH | 1.07A | 3.54A | 4.54A |
| 4.8µH | 1.05A | 3.52A | 4.52A |

4.7µH 的典型纹波约为 3A 负载的 36%，接近手册约 30% 的设计建议；2.2µH 的纹波约 76%，但不能据此认定它无法稳压。
若按 4.7µH 的 -20% 公差、手册 480kHz 频率下限估算，纹波约 1.68A，3A/4A 负载峰值约 3.84A/4.84A。
频率下限的手册测试条件为 VIN=12V、VOUT=3.3V，该估算用于余量检查，不代表 5V 输出的完整保证边界。

## 能沿用当前尺寸的具体候选

**MCS0630-4R7MPY1，C2937097** 是现有系列的 4.7µH 款。

厂家 MCS0630-XXXMY1 规格表（25°C，典型值）给出：

| 项目 | 2.2µH 款 | 4.7µH 款 |
| --- | ---: | ---: |
| 额定电流（约 40°C 温升） | 8.0A | 5.5A |
| 饱和电流（电感下降约 30%） | 12.0A | 7.0A |
| DCR 典型 / 最大 | 17 / 20mΩ | 37 / 40mΩ |
| 外形 | 最大长 7.3mm、宽 6.6±0.2mm、高最大 3.0mm | 同系列外形 |

按 3A 负载估算，仅绕组直流和纹波铜损约为 0.16W / 0.34W；这不包含磁芯损耗。
因此 4.7µH 的纹波更小，但该系列 4.7µH 款的铜损更高，负载突变时的电流爬升也更慢。
MP2236 手册为追求高效率建议 DCR 小于 15mΩ；这不是绝对可用性门槛，但提示最终选型应优先查低 DCR 的 4.7µH 器件。
若使用上面的 PSA 候选，需在实际板上验证持续 3A/4A 的电感温升、负载阶跃和输出电压纹波。
若实际目标改成持续 6A，则不能按这份 3A/4A 核对直接采用额定 5.5A 的款型。

## 焊盘与 3D

现有 L1/L2 焊盘中心 X=±3.533mm，尺寸 3.048×3.419mm；厂家推荐焊盘外跨度约 7.4mm、内间距约 3.7mm、高度 3.5mm。
当前焊盘外跨度约 10.114mm、内间距约 4.018mm，属于向外明显扩大的导入焊盘，并非厂家推荐焊盘的精确复刻。
它与该系列底部端子有重叠；本次没有改焊盘或走线。确定最终采购料号后，仍应按厂家 land pattern 检查焊接余量及邻近间距。
本次 3D 使用 `L_TechFuse_SL0630.step`，高度 3.0mm，标注为尺寸替代模型。
