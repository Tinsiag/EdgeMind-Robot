# FPGA 资料索引

本目录从 `/home/smallcoral/Dev/fpga/ACG720` 中筛选而来，只保留与 EdgeMind-Robot 当前方案直接相关的开发文档、硬件资料和机械模型。

**公开仓库说明：**本地目录保留原厂 PDF、表格和机械模型，GitHub 仓库仅收录我们撰写的 Markdown 索引与核对记录。下文指向原厂附件的相对路径需要在本地资料包中打开；若从 GitHub 克隆，需从厂家或购买渠道获取原始资料，不应将这些附件重新公开分发。

整理日期：2026-09-23。

## 重要注意事项

- ACG720 资料同时涉及 GW5AT-138K 和 GW5AT-60K，工程器件、完整料号、引脚与配置手册必须按实物板卡选择。
- `04_机械模型` 的原始目录名为 `ACX720-V3机械文件`，不能直接认定其尺寸与 ACG720 完全一致；开孔、连接器位置和板框必须按实物或正式机械图复核。
- 原 ACG720 资料包没有独立的 MG513X/MG513XP28 电机数据手册，也没有 DRV8874 数据手册。现已在本地 `doc/电机/WHEELTEC 直流电机附送资料` 找到 WHEELTEC 的 MG513X 手册，可确认 1:28、12 V、0.36 A 额定、3.2 A 堵转等系列参数；实物编码器版本和实际电流仍需核对。两种拟用电机的铭牌与接线记录见 `doc/电机/拟用电机资料核对.md`。原厂手册不随公开仓库上传。
- `08_电机与驱动` 中的旧 PID 工程面向 TB6612；BTS7960/IBT-2 也是来源目录中的备选资料。当前项目计划优先评估 DRV8874，这些资料只能作为参考，不能替代最终驱动选型验证。
- 摄像头 V5 资料对自动对焦和补光能力存在版本描述冲突，应以手头模块实物、原理图和测试结果为准。
- 教程 PDF 中的示例参数、CST 和器件选择不一定都适用于当前板型，移植时应重新核对时钟、复位、IO 电压和时序约束。
