## 一、项目概述

### 1.1 项目背景

本项目基于现有双轮差速底盘和 ACG720 FPGA 开发板，开发一套可在受控室内场地运行的自主移动机器人，用于工程实践及项目展示。

系统利用 FPGA 实现实时采集、轮速闭环、安全联锁和视频处理，由 FPGA 内部软核处理器完成传感器驱动、姿态与里程计计算、路径点导航和绕障决策。基础功能稳定后，可增加外部 AI 计算平台，实现指定目标识别与低速靠近。

### 1.2 项目目标

1. 实现双轮电机闭环调速，支持前进、后退、转向、定点旋转与停止。
2. 实时获取编码器、姿态和近距离障碍信息，并识别关键数据失效。
3. 同屏显示摄像头画面、机器人运行状态和主要传感器数据。
4. 在已知起点的小场地内完成预设路径点任务，绕过简单静态障碍后继续导航。
5. 在急停、碰撞、控制超时或关键故障发生时停止运动，并记录原因。
6. 通过可重复的测试和演示，证明系统功能、稳定性与安全保护效果。

项目优先完成实时控制、系统稳定性和自主导航，AI 功能作为扩展项。

### 1.3 需求约定

- “应”“必须”表示基础版本需要满足的要求。
- “可选”表示独立扩展范围，不作为基础版本交付的必要条件。
- 性能数值为沿用原方案的拟定设计与验收目标，不表示已经实现；最终测试条件和指标在验收前确认。
- 本文规定系统需要具备的能力。具体算法、RTL 文件划分、寄存器地址和调试步骤由详细设计确定。

## 二、使用场景与项目范围

### 2.1 使用场景

| 场景 | 使用方式 | 预期结果 |
| --- | --- | --- |
| 上电与检查 | 操作者上电并查看状态 | 电机保持禁用，系统报告初始化和自检结果 |
| 手动调试 | 操作者通过调试端发送运动命令 | 小车按指令低速运动，并接受安全限制 |
| 路径点导航 | 设置起点、初始朝向和路径任务 | 小车依次到达目标点，完成后停车 |
| 简单绕障 | 路径上设置可被测距传感器识别的静态障碍 | 小车减速、选择方向、绕行并恢复导航 |
| 异常处理 | 触发急停、碰撞、控制失联或关键传感器故障 | 小车停止，显示并记录原因 |
| AI 演示，可选 | 指定目标并进入 AI 模式 | 小车识别目标、对准并低速靠近，目标丢失后停车 |

### 2.2 基础版本范围

基础版本面向平整室内地面、已知起点和初始朝向、3～5 个预设路径点，以及具有足够绕行空间的简单静态障碍场景。自主运行初始速度范围为 0.15～0.25 m/s，最终限速由制动和感知测试确定。

基础导航采用相对定位。六轴 IMU 与轮式里程计融合仍会产生漂移，路径到达误差应由外部测量验证。

### 2.3 可选扩展与范围边界

- AI 扩展：指定目标识别、目标方位输出、低速对准与靠近；搜索和简单跟随可在该扩展内继续评估。
- LiDAR 扩展：基础功能验收后评估 LD06 接入、感知增强及后续导航方案。
- 基础版本不包含完整 SLAM、绝对无漂移定位、任意复杂环境导航，以及复杂动态障碍处理。
- 三路前向 ToF 的感知范围有限。基础版不要求自主长距离倒车；原地转向须考虑车体侧后方的扫掠空间。

## 三、系统组成与职责

### 3.1 系统分工

| 组成 | 职责 |
| --- | --- |
| FPGA 硬件逻辑（RTL） | 编码器采集、轮速闭环、PWM、驱动输出、安全联锁、时间戳、通信外设及视频流水线 |
| FPGA 内部软核程序 | 传感器初始化与读取、姿态融合、里程计、路径任务、绕障和运行调度 |
| 显示与调试端 | 显示图像和状态，发送任务与调试命令，查看参数和日志 |
| LicheePi 4A，可选 | 目标识别、视觉结果处理与任务请求，通过通信接口接入 FPGA |

导航与 AI 只提交运动目标，最终电机输出由 FPGA 运动控制和安全模块共同管理。安全模块对驱动输出拥有最高优先级的禁止权限。软核方案应与实际 FPGA 型号、工具版本和 BSP 匹配，基础版本采用裸机任务调度。

| LiDAR，可选 | LD06 | 1 个 | 后续扩展评估 |

## 四、功能需求

### 4.1 系统启动与运行管理

| 编号 | 功能 | 需求描述 |
| --- | --- | --- |
| FR-SYS-01 | 上电初始化 | 系统应完成控制、传感器、通信及显示相关初始化并报告结果；上电、复位和程序下载期间电机保持禁用。仅在自检通过、相关数据有效且显式解锁后允许运动。 |
| FR-SYS-02 | 运行模式管理 | 系统应支持手动控制和路径导航；启用 AI 扩展后增加 AI 模式。同一时刻仅允许一个控制模式提交有效运动请求，切换模式时应先停止并使旧命令失效。 |
| FR-SYS-03 | 状态管理 | 系统应区分未解锁、就绪、运行和故障状态，并提供可查询的状态信息。任务完成或停止后应退出运行状态；故障清除后回到未解锁状态。 |

### 4.2 底盘运动与闭环控制

| 编号 | 功能 | 需求描述 |
| --- | --- | --- |
| FR-MOT-01 | 基本运动 | 系统应支持前进、后退、左右转向、定点旋转和停止。自主任务应遵守已确认的速度与转向限制；基础后退动作在受控空旷场地低速验证。 |
| FR-MOT-02 | 轮速闭环 | 系统应分别采集左右轮编码器反馈并进行闭环调速，提供目标轮速、实测轮速及输出状态，支持轮径、编码器计数和控制参数的标定配置。 |
| FR-MOT-03 | 输出约束 | 正常调速应限制速度变化率、输出幅度并保护换向过程；异常编码器反馈应被检测。急停和严重故障应绕过普通调速斜坡，由安全逻辑直接限制最终输出。 |

### 4.3 传感器采集与状态估计

| 编号 | 功能 | 需求描述 |
| --- | --- | --- |
| FR-SEN-01 | 编码器与里程数据 | 系统应提供双轮有符号累计计数、方向、增量和异常跳变信息，两侧向前统一为正，并处理计数回绕与同步读取。 |
| FR-SEN-02 | 姿态与相对航向 | 系统应读取 IMU 数据，支持静止零偏校准和安装坐标变换，输出横滚角、俯仰角及相对初始朝向的航向角，并提供数据有效状态和时间戳。 |
| FR-SEN-03 | 三路距离感知 | 系统应独立识别三颗 ToF，分别输出距离、有效状态与采样时间，识别通信错误和数据过期。测距结果应考虑传感器相对保险杠的安装位置，用于净空判断。 |

### 4.4 摄像头与显示

| 编号 | 功能 | 需求描述 |
| --- | --- | --- |
| FR-VID-01 | 实时视频 | 系统应完成 OV5640 图像采集、缓存和显示。不同采集与显示帧率下应保证帧数据完整，避免持续撕裂、显示卡死或覆盖正在读取的帧。 |
| FR-VID-02 | 状态叠加 | 系统应在视频画面上显示运行模式、当前路径点、姿态、左右轮速、三路距离及故障信息；数据无效或过期时应明确标识，避免将旧值作为有效当前值展示。 |

### 4.5 相对定位与路径点导航

| 编号 | 功能 | 需求描述 |
| --- | --- | --- |
| FR-NAV-01 | 定位初始化 | 系统应支持在静止状态下设置起点和初始朝向，结合编码器与 IMU 更新相对位置和航向，支持轮径、轮距校准及按采样时间对齐数据。 |
| FR-NAV-02 | 路径任务执行 | 系统应支持配置或选择包含 3～5 个路径点的任务，按顺序控制转向与前进、接近目标时减速，满足到达条件后切换目标，全部完成后停车并报告完成状态。 |
| FR-NAV-03 | 任务异常处理 | 系统应支持停止当前任务；定位所需数据失效、命令过期或长期无法接近目标时，应停止并报告原因，等待操作者重新下发任务。 |

### 4.6 避障与导航恢复

| 编号 | 功能 | 需求描述 |
| --- | --- | --- |
| FR-OBS-01 | 减速与保护距离 | 系统应依据当前速度、有效距离和数据时效判断减速及停车条件。距离阈值应覆盖最坏感知与处理延迟、实测制动距离和安全裕量，并具有避免频繁切换的迟滞机制。 |
| FR-OBS-02 | 简单障碍绕行 | 系统应完成减速、选择方向、转离障碍、绕行及恢复原目标导航；设置状态超时、最大绕行距离和尝试次数。无可用方向、碰撞、感知失效或无进展时，应停止并报告原因。 |

### 4.7 安全与故障处理

| 编号 | 功能 | 需求描述 |
| --- | --- | --- |
| FR-SAF-01 | 急停与碰撞联锁 | 急停应通过硬件切断执行器支路；碰撞信号应直接进入硬件安全逻辑，首次触发即发起停止并锁存，不能因常规去抖或导航处理而延迟。 |
| FR-SAF-02 | 超时与故障保护 | 软核心跳超时、当前控制源命令过期、驱动过流或过温、编码器异常，以及当前动作依赖的关键传感器失效时，应禁止相关运动输出并记录原因。基础版前向 ToF 失效时应停车。 |
| FR-SAF-03 | 故障恢复与记录 | 系统应记录故障类型和发生时间，提供查询与清除接口。清除故障、重新解锁、重新下发任务应为明确动作，禁止故障解除或通信恢复后自动继续运动。 |

安全处理优先级为：硬件急停 → 故障与碰撞联锁 → 安全限制 → 当前已授权控制模式。车体从发起停止到完全停住的时间和距离应实测，硬件逻辑响应时间不能替代整车停车时间。

### 4.8 通信、参数与调试

| 编号 | 功能 | 需求描述 |
| --- | --- | --- |
| FR-COM-01 | 命令交互 | 系统应通过 UART 支持解锁、停止、手动速度、路径任务、状态查询及参数设置；报文包含类型、长度、序号、有效期和校验信息，错误或越界命令应被拒绝。 |
| FR-COM-02 | 命令生效与时效 | 左右轮目标与命令有效期应一起生效。有效期按 FPGA 本地接收时间判断，控制源失效后不得持续执行旧运动命令；模式之间不得争夺电机输出。 |
| FR-COM-03 | 状态与日志 | 系统应提供轮速、姿态、距离、任务状态、故障和关键统计信息，支持调参及测试数据记录。调试通信和显示更新不得阻塞关键控制任务。 |

### 4.9 AI 目标识别与靠近，可选

| 编号 | 功能 | 需求描述 |
| --- | --- | --- |
| FR-AI-01 | 视觉目标信息 | 扩展平台应识别指定目标，通过 UART 输出类别、置信度、图像中心偏差、框大小、序号及有效期；应测量处理延迟并丢弃积压图像，基础接口不传原始视频。 |
| FR-AI-02 | 目标对准与靠近 | 进入 AI 模式后，小车应根据有效视觉信息对准目标并低速靠近，由 ToF 施加距离安全限制；目标丢失、数据过期、通信失联或近障碍触发时停车。 |

AI 演示面向目标居中、视线简单、无其他近障碍的受控场景。前向 ToF 的读数用于保守安全限制，不保证等于被识别目标的距离。AI 平台不得绕过 FPGA 的轮速闭环和安全保护。

## 五、接口与系统约束

### 5.1 硬件及通信接口

| 接口 | 要求 |
| --- | --- |
| 电源与急停 | 执行器、FPGA、传感器及可选 AI 支路按各自电压和负载供电，配置保险与适合直流负载的急停切断装置；检查瞬态、回生、接地和峰值负载。 |
| 电机与编码器 | 驱动接口适配 3.3 V 逻辑及实际 IO Bank 电压；驱动使能应具有默认禁用措施。编码器供电与输出电平分别核实。 |
| IMU | 优先采用 SPI，支持器件初始化、数据读取、有效状态与采样时间获取。 |
| 三路 ToF | 共用 I²C、独立 XSHUT，上电逐颗分配地址；核实上拉电压和地址表示方式，避免模块冲突。 |
| 摄像头与显示 | 摄像头 DVP、配置接口及显示接口应与实物板卡和例程匹配，明确时钟、引脚、电平及格式。 |
| 外部 UART | 双方约定波特率和报文格式，支持长度检查、序号、命令有效期和 CRC16 校验；未同步时钟时不直接使用外部时间判断 FPGA 超时。 |
| 软核与 RTL | 通过约定的寄存器接口交换数据和命令，保证多字段命令原子提交、状态一致性快照及跨时钟域数据完整性。 |

### 5.2 公共数据约定

| 数据 | 统一约定 |
| --- | --- |
| 编码器 | 有符号累计计数，两侧向前均为正，定义回绕处理 |
| 轮速与距离 | 对外使用 mm/s 和 mm，定点格式统一；传感器数据附有效标志和采样时间 |
| 位置与角度 | 计算统一使用 m、rad；寄存器可使用 mm、mrad，转换方式在接口文档中固定 |
| 时间 | FPGA 本地时间基准，定义位宽、精度和回绕比较规则 |
| 控制命令 | 模式、目标、序号、有效期和原子生效机制 |
| 故障 | 故障码或位图、发生时间、当前状态及清除条件 |

软核执行、视频缓存和显示访问应避免相互阻塞。若共享外部存储，应验证视频满负载下的最坏控制访问延迟。多位跨时钟域数据应使用握手、FIFO 或一致性快照等机制。

## 六、性能与质量要求

### 6.1 拟定验收指标

以下目标沿用原实施方案。正式测试前应固定速度、载荷、电量范围、地面、障碍布局和测量方法；结果以实测记录为准，不能通过临时放宽条件判定通过。

| 编号 | 项目 | 拟定目标 |
| --- | --- | --- |
| NFR-01 | 轮速精度 | 在明确的非低速测试区间，左右轮稳态误差均争取 ≤5%；低速表现单独记录 |
| NFR-02 | 直行与转向 | 2 m 直线路段横向偏差争取 ≤10 cm；90° 定点转向误差争取 ≤5° |
| NFR-03 | 路径点到达 | 受控场地到达半径先设 15 cm，稳定后可尝试 10 cm；采用外部实际测量 |
| NFR-04 | 绕障成功率 | 固定简单场景连续测试 10 次，争取至少 9 次无碰撞绕行并恢复导航至终点 |
| NFR-05 | 视频显示 | 例程支持时以 640×480、RGB565、约 30 fps 为初始目标，连续运行 30 min 无明显撕裂或卡死 |
| NFR-06 | 整车稳定性 | 控制、传感器、通信和显示同时工作，连续运行 30 min 无意外复位或失控 |
| NFR-07 | 安全保护 | 急停、碰撞、控制超时、软核失效及关键传感器故障均触发预期停止并留下实测记录 |
| NFR-08 | 实时性 | 关键任务周期和最坏延迟可测量；视频、日志负载下仍满足已确定的控制周期及停车净空要求 |

### 6.2 设计参考值

以下为详细设计与调试的起点，不单独作为功能验收结果。

| 项目 | 参考值或要求 |
| --- | --- |
| 轮速闭环 | 约 100 Hz 更新 |
| PWM | 驱动支持时以 20 kHz 起步 |
| IMU 采样与融合 | 约 200 Hz，按实际采样时间处理 |
| ToF | 每路以 20～30 Hz 为目标，按测量预算和干扰测试确认真实刷新率 |
| 导航 | 20～50 Hz |
| 状态显示与遥测 | 10～20 Hz |
| 自主速度 | 初始限制在 0.15～0.25 m/s，按实测停车能力调整 |

停止距离阈值应包含感知和处理延迟期间的行驶距离、制动距离及安装净空裕量。心跳与命令超时值应根据任务调度和停车距离确定，不能只按软件循环频率设定。

## 七、验收方案

### 7.1 验收条件与判定

验收使用实际整车、固定版本工程和参数配置，记录环境、载荷、电池状态及测量工具。运动精度应由外部距离和角度测量验证；安全逻辑延迟与整车停车时间分别测量。

基础版验收应覆盖所有必选功能及确认后的性能目标。可选 AI 功能单独验收。测试中的故障和未达标项应记录原因、处理结果与复测结论。

### 7.2 功能验收项目

| 测试项 | 对应需求 | 测试内容及通过依据 |
| --- | --- | --- |
| 启动与模式 | FR-SYS-01、FR-SYS-02、FR-SYS-03 | 检查上电、复位、下载和模式切换；电机默认禁用，状态正确，切换后旧命令不能继续驱动 |
| 电机运动与反馈 | FR-MOT-01、FR-MOT-02、FR-MOT-03、FR-SEN-01；NFR-01 | 验证基本动作、正反向计数、轮速阶跃、换向及输出限制；反馈符号正确，满足确认后的轮速目标 |
| 姿态与测距 | FR-SEN-02、FR-SEN-03 | 验证姿态变化、三路测距、数据时效及传感器断开；数值与实际变化一致，失效可识别 |
| 视频与叠加 | FR-VID-01、FR-VID-02；NFR-05 | 连续显示摄像头画面，检查状态同步更新和无效值标识，达到确认后的显示稳定性目标 |
| 相对定位与路径 | FR-NAV-01、FR-NAV-02、FR-NAV-03；NFR-02、NFR-03 | 完成标定、无障碍多点路线、停止及无进展测试；以外部测量检查精度，到终点停车并报告完成 |
| 绕障与恢复 | FR-OBS-01、FR-OBS-02；NFR-04 | 验证减速、绕行、恢复原任务，以及无路可走和超时情况；成功率达标，失败场景正确停车 |
| 安全联锁 | FR-SAF-01、FR-SAF-02、FR-SAF-03；NFR-07 | 触发急停、碰撞、当前控制源失联、软核卡死、关键传感器断开，并通过受控故障输入验证驱动和编码器异常保护；停止并记录原因，恢复后不自动运动 |
| 通信与调试 | FR-COM-01、FR-COM-02、FR-COM-03 | 发送正常、校验错误、越界和过期命令，查询状态与参数；正确执行或拒绝，双轮命令一致生效，日志可记录 |
| 综合运行 | NFR-06、NFR-08 | 同时启用运动、感知、视频和通信，测量任务周期、最坏延迟与稳定性，验证实际停车净空 |
| AI 扩展，可选 | FR-AI-01、FR-AI-02 | 验证识别、对准、低速靠近及目标丢失、遮挡、旧图像和串口断开；无效输入不导致持续运动 |

### 7.3 验收记录

应交付轮速阶跃曲线、制动距离记录、路径重复实验结果、故障注入记录、综合运行日志或视频，以及 FPGA 时序和资源报告。各项记录标明工程版本、参数与测试条件。

驱动异常验证采用受控限流、安全负载或故障信号注入方式；制动测试覆盖不同速度、载荷、电量和地面条件。

## 九、项目阶段与里程碑

项目按阶段组织，不规定逐周任务。各阶段以可验证结果作为完成条件，实际工期根据硬件到位和联调情况安排。

| 阶段 | 主要内容 | 阶段完成条件 |
| --- | --- | --- |
| 基础确认与平台搭建 | 确认需求、硬件、供电、接口和测试场地；验证软核及视频基础例程 | 电气与接口条件明确，急停有效，上电及复位不转轮，单轮反馈与调速可用 |
| 核心功能开发与集成 | 双轮闭环、传感器、通信、安全联锁、视频和状态显示 | 基本运动、感知、显示可同时运行，关键异常可检测并停车 |
| 自主任务与整车验证 | 里程计标定、路径点导航、绕障恢复及故障测试 | 在约定场景完成路径和绕障任务，达到确认后的性能与稳定性目标 |
| 验收与交付 | 固定工程和参数，完成复测、文档及演示 | 必选需求验收完成，交付物齐全，操作和演示可重复 |

AI 扩展在核心功能稳定后单独推进和验收；LiDAR 另行评估。工期受限时优先调整可选扩展范围，基础安全与整车验收仍作为交付条件。

现有电机资料标称减速比 1:28、额定电流 0.36 A、堵转电流 3.2 A，均为单台参数，驱动选型仍须结合实际负载验证。若编码器 13 PPR 表示电机轴每相周期数，则四倍频理论值为 1456 counts/输出轴转；实际采用左右电机各自标定值。

原资料中的 ACG720 输入范围为 6～12 V，仍须按实物手册确认。普通三串锂电池满电可达 12.6 V，应根据确认后的允许范围设计供电，不能仅凭电池标称电压直接接入板卡。
