## 1. 结论先行

建议第一版采用以下主架构：

```text
3S Li-Po（约 9~12.6V）
  │
  ├─ XT60/大电流端子 → 主保险丝 → 防反接MOS → TVS/母线电容 → VBAT
  │
  ├─ DRV8874 ×2 → MG513 直流减速电机 ×2
  ├─ DRV8825 ×2 → 42BYGH34-401A 步进电机 ×2（若本车确实需要）
  ├─ SY8368A 5V降压 ×1 → TPS25810 → USB-C → ACG720 FPGA
  ├─ SY8368A 5V降压 ×1 → TPS25810 → USB-C → Lichee Pi 4A
  └─ 5V支路 → 低噪声3.3V稳压 → 编码器、IMU、ToF
```

### 核心推荐

1. **MG513 驱动继续采用 DRV8874PWPR ×2**，不要退回 TB6612FNG。
2. **两个计算板必须使用两个独立5V降压级和两个独立USB-C源端**，不共用一颗3A降压器，也不把两路5V输出并联。
3. USB-C 每口优先使用 **TPS25810RVCR**，它同时完成CC识别、3A电流宣告、受控VBUS和端口保护，比“仅两只Rp电阻＋5V直连插座”更适合机器人电源板。
4. 每路5V降压优先评估 **SY8368AQQC（固定5V、8A同步降压）**。虽然8A标称有余量，但价格低、瞬态余量大，USB-C端再由TPS25810限制到规范的3A。
5. 若两只42步进电机确实会上车，使用 **DRV8825PWPR ×2**；若只是未来扩展，建议首板保留接口和可选焊盘，不一定立即焊接，以降低成本、面积和热负荷。
6. 建议至少使用 **4层板、2oz外层铜**；如果坚持2层板，必须明显加宽/铺铜、增加过孔阵列并降低对连续大电流能力的预期。

## 2. 已确认的主要电气需求

| 项目 | 需求/边界 |
|---|---|
| 电池 | 3S Li-Po，11.1V标称，满电约12.6V，3600mAh |
| 底盘电机 | MG513XP28_12V ×2，单台额定0.36A、堵转3.2A |
| 步进电机 | 42BYGH34-401A ×2，1.5A/相，两相四线 |
| FPGA | ACG720，目标经独立USB-C输入5V；必须先确认该Type-C口确实支持整板供电 |
| AI板 | Lichee Pi 4A，经独立USB-C输入5V，建议5V/3A |
| 传感器 | 编码器×2、ICM-42688-P、VL53L1X；建议3.3V/0.5A以上 |
| 控制电平 | FPGA侧按3.3V逻辑设计 |
| 电机急停 | 切断/禁止电机驱动，但尽量保留计算板供电以记录故障、让Linux正常关机 |

### 定板前最大的前置条件

**必须先确认ACG720对应硬件版本的Type-C口是整板5V供电口，而不只是USB-UART/JTAG/通信口。**需要确认：

- VBUS是否进入主电源路径；
- 允许输入电流；
- 是否需要电源选择开关；
- 与原DC输入口之间有无防反灌；
- 带OV5640时的启动和峰值电流。

确认之前可以完成原理图框架和PCB预布局，但不建议直接投板。

## 3. 主芯片选型与立创采购建议

## 3.1 两路5V大电流降压

### 推荐：SY8368AQQC ×2

| 项目 | 内容 |
|---|---|
| 厂牌/型号 | Silergy 矽力杰 SY8368AQQC |
| 立创编号 | **C207642** |
| 封装 | QFN-12 3×3mm |
| 输入范围 | 4~28V |
| 输出 | 固定5V，标称连续8A |
| 检索库存 | 约14K+ |
| 检索单价 | 1+约¥5.10；10+约¥4.10 |
| 用量 | 2颗，ACG720和Lichee Pi各一颗 |

**选择理由：**

- 3S电池全电压范围内可工作；
- 同步降压效率和热表现优于TPS54331、MP1584一类非同步3A方案；
- 价格不高，却能为3A USB-C负载留出足够的负载瞬态余量；
- 两路完全独立，可减少Lichee Pi负载突变对FPGA电源的影响。

**注意：**

- “8A”不是PCB做好后就一定能长期输出8A；电感、输入输出电容、散热焊盘、铜皮面积和环境温度共同决定能力。
- 本项目每路只按USB-C 5V/3A对外使用，不宣告4A或8A。
- 必须按原厂参考设计核算电感饱和电流、纹波电流和环路相关器件。

### 不建议作为主5V/3A口的方案

| 器件 | 不作为首选的原因 |
|---|---|
| TPS54331DR（C9865） | 价格低、库存大，但为非同步3A芯片；3A即接近上限，二极管损耗与发热较大，给Linux板供电余量不足 |
| MP1584EN-LF-Z（C15051） | 也是非同步3A方案；当前小批量页面价格不占优势，且3A输出没有足够余量 |
| TPS62133RGTR（C73973） | 固定5V/3A、性能好，但1+约¥10.28，电流仍只有3A，综合性价比低于SY8368A |

## 3.2 USB-C 5V源端控制

### 推荐：TPS25810RVCR ×2

| 项目 | 内容 |
|---|---|
| 厂牌/型号 | TI TPS25810RVCR |
| 立创编号 | **C473913** |
| 封装 | WQFN-20-EP 3×4mm |
| 工作电压 | 4.5~6.5V |
| 功能 | USB-C DFP源端、连接检测、STD/1.5A/3A宣告、受控VBUS、放电与保护 |
| 检索库存 | 约861 |
| 检索单价 | 1+约¥4.28；10+约¥3.46 |
| 用量 | 每个USB-C口1颗，共2颗 |

**推荐原因：**固定5V、最高3A的USB-C供电不需要USB-PD协商，但仍不能只把5V直接连到Type-C插座。TPS25810能以较低成本完成规范的CC宣告和受控VBUS，适合本项目。

设计要求：

- 配置为5V/3A电流能力宣告；
- VBUS从对应SY8368A输出进入TPS25810，再进入插座；
- 每个口各自保留故障状态、使能控制和测试点；
- 两个端口的VBUS绝不能硬并联；
- USB-C只走供电时，D+/D−、高速线可不接，但需在原理图明确NC；
- 每口增加低电容ESD器件保护CC脚，VBUS使用适合5V电源口的TVS/ESD器件。

### USB-C插座

初选 **GCT USB4105-GF-A-120，立创编号C5184243**，16P Type-C母座，检索1+约¥5.62、库存约3.8K。

但连接器属于机械关键件，定板前必须再核对：

- VBUS触点额定电流不低于3A；
- 外壳固定脚形式和PCB厚度匹配；
- 插拔寿命；
- 嘉立创EDA封装尺寸与原厂图纸完全一致；
- 尽量选带通孔外壳固定脚的型号，避免机器人振动导致纯贴片插座脱焊。

## 3.3 MG513直流电机驱动

### 推荐：DRV8874PWPR ×2

| 项目 | 内容 |
|---|---|
| 厂牌/型号 | TI DRV8874PWPR |
| 立创编号 | **C1855818** |
| 封装 | HTSSOP-16-EP |
| 电机电压 | 可覆盖3S电池母线 |
| 功能 | 单路全桥、3.3V逻辑、电流检测/限流、故障输出 |
| 检索库存 | 约28K+ |
| 检索单价 | 1+约¥6.30；10+约¥5.47；30+约¥4.68 |
| 用量 | 2颗，每台MG513独占一颗 |

这是当前方案中合理且性价比较高的选型。相比TB6612FNG，DRV8874的电流余量、限流、电流反馈和故障诊断更适合堵转电流3.2A的MG513。

### 建议初始限流

文档中的初值可继续作为打样起点：

- VREF分压：13kΩ/20kΩ；
- IPROPI电阻：约1.8kΩ；
- 目标典型斩波阈值：约2.4A/台。

但必须根据所用DRV8874数据手册版本重新计算，首板把VREF分压下臂和IPROPI电阻做成易替换封装，并预留测试点。2.4A限流值不是允许长期2.4A运行的证明。

### 布局要求

- 芯片裸露焊盘下铺完整散热铜并布置过孔阵列；
- VM与PGND回路尽可能短；
- 每颗芯片旁放100nF陶瓷＋1µF/4.7µF陶瓷，并在两路驱动附近放置低ESR大容量电解/固态电容；
- 电机输出端预留RC吸收或TVS焊盘，最终参数通过示波器测量尖峰后确定；
- nFAULT、IPROPI各自引到FPGA，并保留测试点；
- IN1/IN2或PH/EN相关使能引脚必须有硬件下拉，保证FPGA未配置时电机不转。

### 不推荐TB6612FNG

TB6612FNG每路平均电流能力不足以稳妥覆盖MG513启动、冲击与接近堵转工况。其3.2A是峰值概念，不能等价于3.2A堵转持续承受能力。

| 立创编号 | **C2150710** | **C81582** |

| VM范围 | 4.75~29V | 8.2~45V |

| 特点 | StealthChop2静音、UART配置、运行平顺 | STEP/DIR简单、资料成熟、手工调试容易 |
| 检索库存 | 约12K+ | 约17K+ |
| 检索单价 | 1+约¥16.79；10+约¥15.01 | 1+约¥14.59；10+约¥12.72 |

**最终建议：**如果两只42步进电机用于云台、升降等需要安静和平顺的机构，选TMC2209，单颗仅比DRV8825贵约2元，综合性价比更高；如果团队更熟悉传统STEP/DIR、希望HTSSOP更易焊接和示波器调试，则选DRV8825。两者都必须按1.5A/相实测温升，不能把芯片峰值能力当作连续能力。LV8729虽适合此电流档，但立创自营页面已停售，不作为新设计首选。

### 重要注意事项

- 必须实测两台电机每相绕组电阻；
- 使用低温漂电流采样电阻，功率和脉冲能力留足余量；
- 1.5A/相时芯片和PCB会明显发热，必须使用裸露焊盘、散热过孔和较大铜面；
- 预留风扇接口或小散热片安装空间；
- VM旁陶瓷电容和大电解必须靠近驱动器，长线供电尤其要防LC尖峰；
- nSLEEP/nRESET默认拉到安全状态；
- 步进电机停止保持会持续耗电发热，软件应支持空闲降流或关闭保持。

### 是否一定要焊两颗DRV8825

若两只步进电机不是第一版机器人必需功能，建议：

- PCB保留DRV8825完整焊盘、端子和控制接口；
- 第一批只焊一颗或不焊；
- 先完成底盘、FPGA、Lichee Pi和直流电机的供电验证。

这样能降低首板BOM成本约¥25~30，并减少初期排查变量。

## 3.5 3.3V传感器支路

传感器预计电流不大，但考虑两个编码器、IMU、ToF及扩展，建议设计为3.3V/1A能力。

### 推荐方案

从其中一路稳定5V经独立低噪声稳压得到3.3V：

- 若实测总电流小于200mA：可选低噪声LDO，简单且干净；
- 若希望预留到0.5~1A：优先使用1A同步降压器，再在IMU电源前增加磁珠＋局部低噪声LDO/RC滤波。

不建议直接用AMS1117-3.3承担0.5A：从5V降到3.3V时理论发热约0.85W，且噪声和瞬态性能一般。

建议分网：

- `3V3_SENSOR`：编码器、ToF模块；
- `3V3_IMU`：由3V3_SENSOR经磁珠/滤波后供IMU；
- 每个外接传感器接口旁放100nF，适当增加1~10µF。

模块输入电压必须按购买的成品模块核实，不能把VL53L1X裸芯片规格与转接板输入规格混用。

## 4. 输入、保护和安全器件建议

## 4.1 电池输入接口与保险

- 电池接口优先使用板外短线XT60，或额定电流足够的高电流端子；普通2.54mm排针不可作为主动力入口。
- 主保险丝建议采用可更换汽车片式保险丝座或板外保险丝，首版额定值不要仅凭“20A布线目标”直接决定，应在实测整车峰值和线材能力后选定。
- 两类电机支路建议分别设置保险/电子保护，计算板5V支路独立保护。

## 4.2 防反接

首选P沟道MOS高边防反接或专用理想二极管控制器＋N沟道MOS。由于可能存在十几安培瞬态，MOSFET应满足：

- VDS至少30V，优先40V；
- 低RDS(on)，在实际VGS下给出参数；
- SO-8/PowerPAK/LFPAK等可散热封装；
- 按20A短时电流核算导通损耗与安全工作区。

不建议主输入串普通肖特基二极管，压降和发热较大。

## 4.3 TVS和母线电容

- 3S电池母线TVS建议从 **SMBJ15A** 档位开始评估，而不是直接采用5V TVS；必须结合实测回生尖峰确认其反向工作电压和钳位电压。
- 若尖峰钳位后仍可能超过降压器28V上限，需要加强TVS、吸收网络或分隔输入滤波，不能只依赖芯片绝对最大值。
- 输入端建议至少预留：100nF陶瓷、1µF陶瓷、10~22µF高压陶瓷，以及470~1000µF/25V低ESR电解或固态电容焊位。
- 大电容最终容量需结合线长、电机换向和回生波形确定。

## 4.4 急停

急停不要让小型按钮直接承担全部动力电流。推荐：

- 急停按钮控制额定合适的直流接触器/大电流高边开关；
- 硬件同时拉低所有DRV8874与DRV8825的使能/睡眠脚；
- 计算板和传感器供电尽量保留；
- FPGA能够读取急停状态并锁存故障；
- 断电并不等于立即制动，必须实测停车距离。

- 不装步进驱动：约 `2×5.10 + 2×4.28 + 2×5.62 + 2×6.30 ≈ ¥42.6`；
- 加装两颗DRV8825：再加约 `2×14.59 ≈ ¥29.2`；

## 6. PCB分区和布线建议

建议按以下顺序从板的一端排到另一端：

```text
电池入口/保险/防反接/TVS
        ↓
动力母线与大电容
  ├─ DRV8874区 → DC电机端子
  ├─ DRV8825区 → 步进电机端子
  └─ 两个独立Buck区
          ↓
    两个TPS25810＋USB-C口
          ↓
    3.3V传感器与逻辑接口区
```

具体规则：

1. 电机功率地、降压功率地与传感器地采用分区回流，在电池入口/母线电容附近形成明确汇合点。
2. 不要切割控制信号下方的参考地平面。
3. 每个开关电源的高di/dt热环路必须极小，不要让SW节点铺铜过大。
4. 电机输出、SW节点远离IMU、编码器和USB-C CC走线。
5. 驱动器裸露焊盘下使用密集散热过孔连接内层/底层铜。
6. 大电流铜皮避免“细颈”；连接器焊盘到铜皮的过渡也要按电流核算。
7. 每路电源放置输入、输出和使能测试点；DRV8874放置IPROPI和nFAULT测试点。
8. 所有外接控制输入增加串联小电阻焊位，便于抑制振铃和调试。
9. 编码器接口建议增加施密特缓冲/RC可选焊盘和ESD保护，但滤波时间不能达到按键去抖级别。
10. FPGA到电机驱动的安全禁止信号应有硬件默认下拉，并尽可能能够同时禁止全部驱动。

## 7. 第一版建议的可制造配置

为了降低一次性失败风险，建议首板采用以下装配策略：

### 必装

- 输入保护与母线；
- SY8368A ×2；
- TPS25810 ×2；
- USB-C ×2；
- DRV8874 ×2；
- 3.3V传感器支路；
- 电压、电流、故障测试点；
- 急停/总使能接口。

### 可选焊

- DRV8825 ×2及其采样电阻；
- 电机端RC吸收；
- 额外母线电容；
- 编码器施密特缓冲；
- 风扇接口和温度传感器。

### 强烈建议分阶段上电

1. 不焊主芯片，先检查电池输入无短路；
2. 只焊第一路5V，使用电子负载验证0.5A、1A、2A、3A及热稳定；
3. 验证TPS25810和USB-C插拔、短路、过流和断电放电；
4. 重复验证第二路5V；
5. 接Lichee Pi，测启动、CPU负载和USB外设情况下板端电压；
6. 在确认ACG720 Type-C供电路径后再接FPGA；
7. 单独焊接并验证一颗DRV8874，先用小电机/限流电源测试；
8. 再接MG513，测试空载、启动、换向、接近堵转和温升；
9. 最后验证第二路直流电机与可选步进驱动；
10. 做全负载、电池低电压、电机换向和急停测试。

## 9. 最终推荐版本

### 方案A：最低BOM、仍保持可靠（推荐先评估）

- `SY8368AQQC ×1`：做中央5V/8A同步降压；
- 每个USB-C口各一颗受控限流/反灌阻断eFuse或load switch；
- 每个USB-C口各一套CC检测/源端控制，检测到对端Rd后才接通VBUS；
- `USB4105-GF-A-120 ×2`；
- `DRV8874PWPR ×2`；
- 步进部分在`TMC2209-LA-T ×2`与`DRV8825PWPR ×2`中二选一；
- 独立3.3V/1A传感器电源；
- 主输入保险＋防反接MOS＋合适TVS＋足量25V母线电容。

该方案在两个Type-C端口仍保持独立过流、短路和反灌保护的前提下，比两颗5V Buck更省成本、更省板面积。缺点是两块计算板共用中央5V降压，若一口严重短路而eFuse故障或布局不当，可能影响另一口；因此中央5V必须选真正连续≥8A、28V级输入、具备良好热设计的同步Buck，并在每口加独立保护。

### 方案B：故障和噪声隔离优先

- `SY8368AQQC ×2`：ACG720和Lichee Pi各一颗；
- `TPS25810RVCR ×2`：每口完成CC检测、3A宣告和受控VBUS；
- `USB4105-GF-A-120 ×2`；
- `DRV8874PWPR ×2`；
- `TMC2209-LA-T ×2`（静音优先）或`DRV8825PWPR ×2`（易调试优先）；
- 独立3.3V/1A传感器电源。

方案B成本略高，但调试最直观：Lichee Pi负载突变、电机噪声或单路故障对另一块计算板的影响最小。若FPGA和Lichee Pi同时承担关键任务，建议采用方案B。

### USB-C源端的强制要求

- 不要把“Rp电阻＋永远带电的VBUS”当作正式方案；
- USB-C源端应通过CC1/CC2检测到对端Rd后再接通VBUS；
- 3A广告通常为CC1、CC2各约10kΩ到5V（最终按控制器数据手册配置）；
- 受电板必须确认是sink，避免两端都是source时互相顶电；
- 各口都要有VBUS限流、软启动、短路保护和反向电流阻断；
- 测试时核对插拔、短路、断电和调试线缆接入时的反灌行为。

### 回生与母线保护

满电12.6V时，电机急减速可能把能量回灌到VBAT，使母线高于正常电池电压。TVS只适合吞瞬态，不能替代持续制动能量处理。必须：

- 通过速度斜坡限制制动和换向；
- 在动力母线附近放置足量低ESR电容；
- 示波器实测急停、急减速和换向尖峰；
- 若回生明显，增加制动钳位/耗能电阻方案，或确认电池能安全吸收回生电流；
- 不能仅凭SMBJ TVS就宣称母线长期安全。

该配置兼顾了成本、现货、调试难度和保护能力。真正决定首板能否稳定工作的重点，不只是芯片型号，而是：**ACG720 Type-C供电确认、USB-C源端CC握手、5V降压的连续电流与热设计、DRV8874/步进芯片裸露焊盘散热、大电流回流路径、母线回生与急停设计。**
