# ACG720 / AT8236 接线

信号球号来自2026-10-14用户重接线及板端网络截图，当前A745继续使用下表。
历史维修记录中曾报告3.3V对地短路，电气根因未确认；2026-11-02用户报告编码器VCC为3.3V，此为用户描述，未实测电压/波形。
当前固件和实体验收见[项目状态](../../docs/project-status.md)，不再使用旧开环/闭环工程或旧位流。

## 八根信号线（当前唯一施工映射）

| 信号网络 | RTL 端口 | FPGA 球号 | 驱动板接口 | 相对 FPGA 方向 |
| --- | --- | --- | --- | --- |
| LAIN1 | left_in1 | A18 | L-1 | 输出 |
| LAIN2 | left_in2 | A19 | L-2 | 输出 |
| LF_ENA | left_enc_a | A15 | L-7 | 输入 |
| LF_ENB | left_enc_b | A16 | L-8 | 输入 |
| RAIN1 | right_in1 | F13 | R-5 | 输出 |
| RAIN2 | right_in2 | F14 | R-6 | 输出 |
| RF_ENA | right_enc_a | E13 | R-2 | 输入 |
| RF_ENB | right_enc_b | E14 | R-1 | 输入 |

RF_ENA 是右编码器 A，RF_ENB 是右编码器 B，不能因描述顺序而互换。LF_ENA/LF_ENB 仍为左编码器 A/B。电机功率线只连接驱动模块 AOUT1/AOUT2，不接 FPGA。地和电源不包含在这八根信号线中。

与旧版不同的六个球号为：left_in1 A13→A18、left_in2 A14→A19、right_in1 F16→F13、right_in2 E17→F14、right_enc_a D20→E13、right_enc_b C20→E14。旧 P7-1/2、P7-31～34 不再作为这些信号的当前接线依据。

## 电源板两排八针定义（板端不变）

以用户截图从左向右数 1～8，方形焊盘为 1 脚。右轮 R 排针：RF_ENB、RF_ENA、3.3V、GND、RAIN1、RAIN2、RBIN1、RBIN2。左轮 L 排针：LAIN1、LAIN2、LBIN1、LBIN2、GND、3.3V、LF_ENA、LF_ENB。

| 针号 | 左电机 L 接口 | 右电机 R 接口 |
| --- | --- | --- |
| 1 | LAIN1 → A18 | RF_ENB → E14 |
| 2 | LAIN2 → A19 | RF_ENA → E13 |
| 3 | LBIN1：未用 B 通道输入 | 3.3 V：供电来源待核对 |
| 4 | LBIN2：未用 B 通道输入 | GND |
| 5 | GND | RAIN1 → F13 |
| 6 | 3.3 V：供电来源待核对 | RAIN2 → F14 |
| 7 | LF_ENA → A15 | RBIN1：未用 B 通道输入 |
| 8 | LF_ENB → A16 | RBIN2：未用 B 通道输入 |

- L-5/R-4 按历史原理图同属 GND，L-6/R-3 同属 3.3 V；须断电实测实板导通，不只依赖网络名字。
- 公共地连到实板已确认的 FPGA GND，不得用普通 GPIO 输出低电平替代。
- 每块模块仅使用 A 通道时，确认实际插接方向后，将 L-3/L-4 接本板 GND、R-7/R-8 接本板 GND；未用 B 输出不接电机。
- 不反插六针电机插头，不将 VM、5 V、桥输出接到 FPGA 信号 IO 或 3.3 V 网络。

## 当前工程依据

活动约束为 `code/camera-car-control/a745-autonomous/constraints/board.cst`，板级副本由prepare生成。
构建与实际PAD审核见[开发说明](../../docs/contributing.md)；修改CST后必须重新综合、布局布线、生成并审查位流。
UserCode不能区分同一版本的重建，须以位流SHA和同源证据核对。

## 接线核实

在断电时核对实际端子、3.3V来源、模块插入方向及公共GND。FPGA球号不是外部排针针号，不猜写P7编号。
公共GND必须连接，不能用普通GPIO输出低替代；旧“GND锁”指FPGA内部输出锁低，不代表拆公共地。
IO_TYPE=LVCMOS33不会改变实板VCCIO；编码器电平、参考端供电、接触与共地仍需按实物核实。
不得并联未经设计的稳压器输出，也不能把VM、5V或桥输出接到FPGA信号IO。

维修后恢复外设时先检查供电，再在VM关闭状态观察传感器；受控运动由本地S1操作。
历史10月接线图和旧构建副本已不作为当前入口；本表与活动CST不一致时先停止并核查实物。
