# AT8236 双路模块资料核对

核对日期：2026-10-02。资料：[用户提供的合并长图](合并长图_1-9.png)、杭州中科微 AT8236-S409-V1.1 芯片手册，以及当前 `pcb/power/kicad/ProPrj_power_2026-10-02` 工程。本记录区分卖家模块标称、芯片推荐条件与本板实际连接，不把图片当作模块温升或限流的实测证明。

## 1. 结论

该资料对应 **MD-AT8236 V1.0 类双路直流有刷电机模块**：每块有两颗 AT8236，每颗一路 H 桥，合计能独立控制两台直流电机。资料中的 TB6612 内容属于另一款产品，不能混用其 PWMA/PWMB、STBY 和 VCC 规格。

3S 电池正常约 9–12.6 V 落在模块标称 VM 范围内，FPGA 3.3 V 控制信号也能满足 AT8236 输入条件。对项目 MG513X 单台额定 0.36 A，模块具有选型基础；但单台 3.2 A 堵转超过模块标称 3 A 持续值，**不能据“6 A 峰值”宣称可持续堵转**，启动、保护阈值和散热仍需实测。

当前原理图使用每块模块的 A 通道，A 输入与 A 输出的网络命名相符，未用 B 输出可以保持不连接。**PCB 的 J6/J8 排针顺序却与模块相反，且排距没有匹配模块尺寸。当前布局不能直接插入模块上电。**

## 3. 模块实物接口与 KiCad 编号

以长图中电容朝上、`MD-AT8236 V1.0` 字样可正常阅读的那张接口照片为准，从上到下：

| 位置 | 左排功能 | 右排功能 |
| --- | --- | --- |
| 1 | AOUT2 | GND |
| 2 | AOUT1 | VM |
| 3 | BIN1 | VCC |
| 4 | BIN2 | AIN2 |
| 5 | VCC | AIN1 |
| 6 | VM | BOUT1 |
| 7 | GND | BOUT2 |

左排 AOUT 与右排 AIN 属于同一 A 通道；左排 BIN 与右排 BOUT 属于同一 B 通道。它们交叉分布在两排上是模块布局，不代表原理图把 A/B 接反。

当前 KiCad 采用两排分别编号的方法，而非模块统一的 1–14 编号。保留当前逻辑网络时，应使用下表：

| KiCad 焊盘号 | J5/J7 左排功能 | J6/J8 右排功能 |
| --- | --- | --- |
| 1 | AOUT2 | BOUT2，当前 NC |
| 2 | AOUT1 | BOUT1，当前 NC |
| 3 | BIN1 | AIN1 |
| 4 | BIN2 | AIN2 |
| 5 | VCC | VCC |
| 6 | VM | VM |
| 7 | GND | GND |

**两排的物理编号必须反向排列。** 当左排沿某方向为 1→7 时，对面的右排沿同方向必须为 7→1，才能对应接口照片。

### 当前连接的正确部分

- 左电机：`J1.1/2 → LAIN1/2 → J6.3/4`；`J5.2/1 → LAOUT1/2 → J3.6/1`。
- 右电机：`J2.5/6 → RAIN1/2 → J8.3/4`；`J7.2/1 → RAOUT1/2 → J4.6/1`。
- J5/J7 的 3、4 脚是 B 通道控制；J6/J8 的 1、2 脚是未接出的 B 通道输出。未用通道应保持 IN1=IN2=0，NC 输出不能拿来并联增加电流。
- 四排的 5 脚都接 `/3.3V`，6 脚接 `/VM`，7 脚接 GND。按接口资料，VCC 均应作为外部参考输入处理；两侧 VCC 是否在模块内部相连仍需实物导通确认。

### 当前 PCB 必须修改的部分

原生 PCB API 读取结果：四排均为 0°，每排焊盘 1→7 的 X 坐标都递增，步距为 2.54 mm。这与上述反向编号要求冲突。沿 J5/J7 的 1→7 方向观察 J6/J8：

| 物理位置 | 模块右排要求 | 当前 PCB 连接 |
| --- | --- | --- |
| 1 | GND | NC |
| 2 | VM | NC |
| 3 | VCC | AIN1 控制网络 |
| 4 | AIN2 | AIN2 控制网络 |
| 5 | AIN1 | `/3.3V` |
| 6 | BOUT1 | `/VM` |
| 7 | BOUT2 | GND |

如果按图直接插接，部分桥输出会接到 VM/GND，控制脚也会错位，有损坏风险。改版时需要将 **J6/J8 绕各自排针中心旋转 180°并重布受影响走线**，或创建包含两排且编号正确的整体模块封装；不能只翻转丝印。

本板 J5–J6 排中心距为 **23.0005 mm**，J7–J8 为 **23.1275 mm**。资料的 23 mm 是模块外形长边，孔中心位于板内，不能拿外形尺寸直接当排中心距；两组现值也不一致。需测量实际模块的两排孔中心距，再统一修改。资料没有给出该数值，本次未把推测值写入封装。

本次重新导出当前原理图网表，核对 J1–J8 共 56 个引脚与 PCB 网络全部一致。这个检查证明文件之间一致，**不能消除模块物理接法错误**。坐标和网络证据见 [接口核对 JSON](../../pcb/power/kicad/review/at8236-interface-audit.json)。

## 4. VCC、限流与 3.3 V 电源

裸芯片没有独立的逻辑 VCC 电源脚，具有 VREF 电流参考脚。模块将 VCC 标为参考输入；它是否直接连接两颗芯片的 VREF、经过分压还是另有电路，应检查模块背面线路或索取原理图。

若模块 VCC 直接进入 VREF 且 ISEN 使用检测电阻，则原厂关系为 `I_TRIP = VREF / (10 × R_ISEN)`。因此 **VCC=3.3 V 不等于限流 3 A**，例如 `R_ISEN=0.1 Ω` 时对应约 3.3 A。长图不同产品照片可见 R005 和 R015 等不同标识，不能仅凭照片确定实物检测阻值和最终限流。需核对实际阻值、连接方式及保护电流，再决定 VCC 接固定 3.3 V 还是专门的参考电路。[原厂手册第 6 页](https://atta.szlcsc.com/upload/public/pdf/source/20210923/1552D95CBAF8BE780D06AE79E7783380.pdf)

当前 `/3.3V` 网络仍没有明确板上电源。既然 VCC 已确认是输入，驱动模块不能被列为该网络的供电来源。应明确由电源板稳压器或经过能力核实的 FPGA 电源提供，并同时覆盖编码器、传感器和参考输入负载。

## 5. 控制逻辑与 FPGA 适配

资料图的真值表如下，Z 表示高阻：

| IN1 | IN2 | OUT1 | OUT2 | 状态 |
| --- | --- | --- | --- | --- |
| 0 | 0 | Z | Z | 滑行；持续低电平后休眠 |
| 1 | 0 | H | L | 正向驱动 |
| 0 | 1 | L | H | 反向驱动 |
| 1 | 1 | L | L | 制动 |

先按资料中的快衰减接法核对输出：正向 `IN1=PWM、IN2=0`；反向 `IN1=0、IN2=PWM`；禁止/复位时两输入均为 0。电机实际“车身向前”仍由线序、安装方向和编码器正方向共同确定。

现有 FPGA 驱动文档描述的是 **TB6612 的 IN1/IN2、独立 PWM 与 STBY**。AT8236 这款模块只有每通道两个 IN，不能只把原 TB6612 的方向 IN 接过来而悬空原 PWM，这会失去调速；也不能把原 STBY 当作本模块已有的独立使能。需要用 PWM 与方向/禁止状态形成两路 AT8236 IN 输出，并检查引脚约束和复位默认状态。该项是驱动接口适配工作，本次资料核对未改 RTL。

`00` 是滑行，不保证立即停止。停止距离、软件制动和硬件急停需要分别验证；参考输入也不能被直接当作已验证的急停使能。

## 6. 进入上电验证前

1. 按实物修正 J6/J8 排列与两组排距，核对模块插入方向及电容/排母高度。
2. 明确 3.3 V 来源；确认 VCC→VREF 路径、检测电阻、限流和模块输入电容耐压。
3. 适配 FPGA 的两个 IN 输出；检查复位、下载、零命令和通信中断时保持禁止。
4. 完成电源保护与现有 PCB 断连修复后，用限流电源分阶段检查空载、启动、换向、接近堵转、温升和母线尖峰。模块过流保护不能代替电池保护或系统故障锁存。

本次确认的是资料参数、接口对应与现有 PCB 差异，尚没有模块实物电流、温升或排距的测试结果。
